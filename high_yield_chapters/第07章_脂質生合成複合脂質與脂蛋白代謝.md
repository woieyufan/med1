## 本章導讀與知識架構定位

人體在飽食與營養充裕狀態下，會將過剩能量轉化為脂肪酸、三酸甘油酯與膽固醇儲存，同時構建細胞膜脂質屏障並透過血漿脂蛋白進行全身調度。

本章下轄四大核心主題：
1. **主題 7.1：脂肪酸從頭合成、三酸甘油酯與類廿烷酸途徑**（檸檬酸接梭、ACC 限速步、FAS 複合體、花生四烯酸與 COX/LOX 發炎途徑及藥物抑制點）
2. **主題 7.2：膜磷脂、鞘脂質代謝與溶小體儲積症**（DPPC 表面張力素與 NRDS、六大鞘脂儲積症 Tay-Sachs/Gaucher/Niemann-Pick/Fabry/Krabbe/MLD 全覽矩陣）
3. **主題 7.3：膽固醇合成、轉化調節與膽汁酸腸肝循環**（HMG-CoA 還原酶、Statin 藥物、SREBP 調節、7$\alpha$-羥化酶、膽汁酸腸肝循環與消膽胺）
4. **主題 7.4：血漿脂蛋白代謝全覽與家族性高血脂症**（五大載脂蛋白 Apo、乳糜微粒/VLDL/LDL/HDL 代謝、PCSK9 機轉、Fredrickson 高脂蛋白血症 Types I~V 對照表）

# 主題 7.1：脂肪酸從頭合成、三酸甘油酯與類廿烷酸途徑

### 重點一：核心高頻速查矩陣

#### 1. 脂肪酸生合成與 $\beta$-氧化對比全覽表
| 比較項目 | 脂肪酸生合成 (De Novo Synthesis) | 脂肪酸 $\beta$-氧化 (Beta-Oxidation) |
| :--- | :--- | :--- |
| **主要發生亞細胞部位** | **細胞質 (Cytosol)**（需檸檬酸接梭自粒線體帶出乙醯基） | **粒線體基質 (Mitochondrial Matrix)** |
| **主要組織器官** | **肝臟（最主要）**、泌乳期乳腺、脂肪組織 | 肝臟、骨骼肌、心肌（紅血球與腦除外） |
| **關鍵限速酵素** | **乙醯-CoA 羧化酶 (Acetyl-CoA Carboxylase, ACC)** | **肉鹼棕櫚醯轉移酶-I (CPT-I)** |
| **輔基與碳載體** | **醯基載體蛋白 (ACP)**（其上有 4'-磷酸泛酸臂） | **輔酶 A (CoA-SH)** |
| **氧化還原輔酶需求** | **消耗 NADPH**（還原作用，源自 PPP 與蘋果酸酵素） | **產出 $\text{FADH}_2$ 與 NADH**（氧化反應供呼吸鏈） |
| **兩碳單位原料形式** | **丙二醯-CoA (Malonyl-CoA, 3C)**（羧化耗 1 ATP） | 游離乙醯-CoA (Acetyl-CoA, 2C) |
| **荷爾蒙調節開關** | **胰島素（去磷酸化活化 ACC）**；檸檬酸異位活化 | **升糖素 / 腎上腺素（PKA 活化 HSL）**；丙二醯-CoA 抑制 CPT-I |

#### 2. 花生四烯酸（Arachidonic Acid, 20:4 $\omega$-6）衍生之類廿烷酸發炎網絡
- **前驅物釋放**：膜磷脂在**磷脂酶 A2（PLA2）**催化下切除釋放花生四烯酸（**類固醇 Steroids 抑制 PLA2**）。
- **兩大代謝分支途徑**：
  1. **環氧化酶途徑（COX-1 / COX-2）**：
     - 生成前列腺素（Prostaglandins, PG）與血栓素（Thromboxane, TX）。
     - **$\text{TXA}_2$**（血小板）：強效**促進血小板凝集、血管收縮**。
     - **$\text{PGI}_2$**（血管內皮）：強效**抑制血小板凝集、血管擴張**。
     - **藥物靶點**：**阿斯匹靈（Aspirin）**不可逆乙醯化抑制 COX-1/2；**NSAIDs（Ibuprofen, Indomethacin）**可逆競爭抑制；**Celecoxib** 專一抑制 COX-2。
  2. **脂氧化酶途徑（5-Lipoxygenase, 5-LOX）**：
     - 生成白三烯類（Leukotrienes, LT）。
     - **$\text{LTB}_4$**：極強的中性粒細胞化學趨化介質（Neutrophil chemotaxis）。
     - **$\text{LTC}_4, \text{LTD}_4, \text{LTE}_4$**：構成過敏性慢反應物質（SRS-A），引起氣管平滑肌強烈持續痙攣與血管通透性增加（氣喘核心介質；**Montelukast 拮抗白三烯受體治療氣喘**）。

# 主題 7.2：膜磷脂、鞘脂質代謝與溶小體儲積症

### 重點一：核心高頻速查矩陣

#### 1. 膜磷脂特色結構
- **肺表面張力素 (Surfactant)**：主要成分為**二棕櫚醯卵磷脂（DPPC / Dipalmitoylphosphatidylcholine）**。第 35 週胎兒成熟前合成不足，導致肺泡表面張力過高塌陷，引發**新生兒呼吸窘迫症候群（NRDS）**。羊水中**卵磷脂/鞘磷脂（L/S 比值）$> 2.0$** 代表肺部成熟。
- **心磷脂 (Cardiolipin)**：雙磷脂醯甘油結構，專一存在於**粒線體內膜**維繫呼吸鏈複合體穩定；抗心磷脂抗體見於抗磷脂症候群（APS）與梅毒 VDRL 偽陽性。

#### 2. 六大鞘脂質儲積症（Sphingolipidoses）終極診斷全表
| 疾病名稱與遺傳型態 | 缺乏之溶小體酵素名稱 | 體內積累之脂質基質 | 典型臨床表徵與病理組織切片特徵 |
| :--- | :--- | :--- | :--- |
| **Tay-Sachs 病**<br>(常染色體隱性) | **己糖胺酶 A**<br>(Hexosaminidase A) | **$GM_2$ 神經節苷脂**<br>($GM_2$ ganglioside) | **視網膜櫻桃紅斑 (Cherry-red spot)、漸進性神經退化、聽覺過敏、無肝脾腫大！** 溶小體洋蔥皮樣結構（Onion-skin lysosomes） |
| **Gaucher 病 (高雪氏病)**<br>(最常見，常染色體隱性) | **葡萄糖腦苷脂酶**<br>(Glucocerebrosidase) | **葡萄糖腦苷脂**<br>(Glucocerebroside) | **顯著肝脾腫大、全血球減少（貧血血小板低）、無菌性骨壞死**、骨骼變形（Erlenmeyer flask 燒瓶樣畸形）；**組織切片見高雪細胞：巨噬細胞胞質呈「揉皺的衛生紙樣 (Crumpled tissue paper)」** |
| **Niemann-Pick 病**<br>(常染色體隱性) | **鞘磷脂酶**<br>(Sphingomyelinase) | **鞘磷脂**<br>(Sphingomyelin) | **視網膜櫻桃紅斑 + 顯著肝脾腫大！** 神經進行性退化；**骨髓抹片見泡沫狀細胞 (Foam cells / 泡狀巨噬細胞)** |
| **Fabry 病 (法布瑞氏病)**<br>(**唯一的 X 聯鎖隱性！**) | **$\alpha$-半乳糖苷酶 A**<br>($\alpha$-Galactosidase A) | 三己糖神經醯胺 (Ceramide trihexoside / Gb3) | **周邊神經劇痛（四肢末端灼痛）、皮膚血管角化瘤 (Angiokeratomas)、少汗症、早發性心臟肥大與腎衰竭** |
| **Krabbe 病**<br>(常染色體隱性) | 半乳糖腦苷脂酶<br>(Galactocerebrosidase) | 半乳糖腦苷脂及神經毒性鞘氨醇半乳糖苷 (Psychosine) | 嚴重周邊神經病變、視神經萎縮、發育停滯、**腦組織出現球狀細胞 (Globoid cells)** |
| **異染性腦白質失養症 (MLD)**<br>(常染色體隱性) | 芳基硫酸酯酶 A<br>(Arylsulfatase A) | 腦硫脂 (Sulfatide) | 中樞與周邊神經廣泛脫髓鞘病變、共濟失調、痴呆；甲苯胺藍染色呈異染現象 |

# 主題 7.3：膽固醇合成、轉化調節與膽汁酸腸肝循環

### 重點一：核心高頻速查矩陣

#### 1. 膽固醇生合成反應與 Statin 標靶
- **合成部位**：主要在**肝細胞質與光滑內質網（SER）**。
- **合成核心步驟**：
  $$\text{2 Acetyl-CoA} \to \text{Acetoacetyl-CoA} \xrightarrow{\text{HMG-CoA synthase}} \text{HMG-CoA} \xrightarrow[\mathbf{HMG-CoA\text{ reductase (限速步)}}]{\mathbf{消耗 2 NADPH}} \mathbf{Mevalonate (甲羥戊酸)}$$
  $$\text{Mevalonate} \to \text{異戊二烯單位 (IPPP, 5C)} \to \text{香葉基 (10C)} \to \text{法尼基 (FPP, 15C)} \to \text{角鯊烯 (Squalene, 30C)} \to \text{羊毛固醇} \to \text{膽固醇 (27C)}$$
- **HMG-CoA 還原酶調節機制**：
  1. **競爭性抑制劑：Statin 類藥物（Atorvastatin, Rosuvastatin）**結構與 HMG-CoA 極其相似，直接佔據活性位點，阻斷內生膽固醇合成。
  2. **SREBP/SCAP 系統轉錄調節**：當細胞內游離膽固醇低下時，SCAP 攜帶 SREBP 移至高基氏體被蛋白酶切除活化，入核促進 HMG-CoA 還原酶與 **LDL 受體（LDLR）**大量轉錄，強勢清除血中 LDL。

#### 2. 膽汁酸（Bile Acids）代謝與腸肝循環
- **限速酵素**：**膽固醇 7$\alpha$-羥化酶（$7\alpha$-hydroxylase，細胞色素 P450 酵素）**，受膽酸回饋抑制。
- **初級膽汁酸（肝臟合成）**：膽酸（Cholic acid）與鵝去氧膽酸（Chenodeoxycholic acid）。均與甘胺酸或牛磺酸結合生成**結合型膽汁酸（膽鹽）**排入膽汁。
- **次級膽汁酸（腸道細菌作用）**：腸道細菌水解去結合基團並進行 $7\alpha$-去羥基化，轉化為去氧膽酸（Deoxycholic acid）與石膽酸（Lithocholic acid）。
- **腸肝循環**：95% 的膽鹽在**迴腸末端（Terminal Ileum）**經主動運輸再吸收經門靜脈回肝；**消膽胺（Cholestyramine，膽酸結合樹脂）**在腸道結合膽酸阻止再吸收隨糞便排出，強迫肝臟消耗更多膽固醇合成膽汁酸，顯著降低血膽固醇。

# 主題 7.4：血漿脂蛋白代謝全覽與家族性高血脂症

### 重點一：核心高頻速查矩陣

#### 1. 五大主要載脂蛋白（Apolipoproteins）功能全覽表
| 載脂蛋白名稱 | 存在之主要脂蛋白 | 核心生理功能與酵素輔因子角色 | 遺傳缺陷相關疾病 |
| :--- | :--- | :--- | :--- |
| **ApoA-I** | **HDL (高密度脂蛋白)**、乳糜微粒 | **活化 LCAT (卵磷脂膽固醇醯基轉移酶)**；驅動反向膽固醇轉運 | 缺乏導致 HDL 極度低下與早發性冠心病 |
| **ApoB-48** | **乳糜微粒 (Chylomicron) 專屬** | 藉由小腸 RNA 編輯（*APOB* mRNA 的 C $\to$ U 形成終止密碼子）生成原長 48% 的片段；負責介導小腸組裝與分泌乳糜微粒 | 無 $\beta$ 脂蛋白血症 |
| **ApoB-100** | **VLDL、IDL、LDL (低密度脂蛋白)** | 肝臟合成全長胜肽；**負責結合周邊細胞膜上的 LDL 受體 (LDLR)** 介導胞吞作用 | 家族性高膽固醇血症 Type IIa（ApoB 突變無法結合受體） |
| **ApoC-II** | 乳糜微粒、VLDL、HDL | **強效活化血管內皮表面之脂蛋白脂酶 (LPL)**，水解 TG 釋出游離脂肪酸供肌肉心臟利用 | 缺乏引發第 I 型高脂蛋白血症（嚴重高三酸甘油酯血症） |
| **ApoE** | 乳糜微粒殘骸、VLDL、IDL、**HDL** | **負責結合肝細胞表面的 ApoE 受體與 LDL 受體**，介導乳糜微粒殘骸與 IDL 被肝臟清除吸收 | **ApoE2/E2 同型合子導致第 III 型高脂蛋白血症**；ApoE4 增加晚發型阿茲海默症風險 |

#### 2. Fredrickson 家族性高脂蛋白血症（Dyslipidemias）分型對照表
| 分型代號 | 遺傳基因缺陷位點 | 血漿中顯著升高之脂蛋白 | 血液中顯著升高之脂質 | 典型臨床表徵與併發症 |
| :--- | :--- | :--- | :--- | :--- |
| **Type I：家族性高乳糜微粒血症** | **LPL 缺乏** 或 **ApoC-II 缺乏** | **乳糜微粒 (Chylomicron)** | **三酸甘油酯 (TG) 極度飆高** ($> 1000\text{ mg/dL}$) | **反覆發作急性胰臟炎**、發疹性黃色瘤 (Eruptive xanthomas)、視網膜脂血症；血清靜置上方浮奶油層；**無早發動脈粥狀硬化風險！** |
| **Type IIa：家族性高膽固醇血症** | **LDL 受體基因突變** 或 **ApoB-100 結合域突變** | **LDL** | **總膽固醇 (TC) 極度飆高** | **早發性動脈粥狀硬化與致命性心肌梗塞**、**跟腱黃色瘤 (Achilles tendon xanthoma)**、角膜老年環 (Corneal arcus) |
| **Type IIb：家族性混合型高血脂症** | 肝臟過度合成 ApoB 或受體減少 | **LDL + VLDL** | **膽固醇與 TG 雙雙升高** | 心血管疾病高風險 |
| **Type III：家族性異常 $\beta$ 脂蛋白血症** | **ApoE2 純合子突變**（無法與受體結合） | **乳糜微粒殘骸 (Remnants) + IDL** | 膽固醇與 TG 雙雙升高 | **掌紋黃色瘤 (Palmar xanthomas)**、結節性黃色瘤、早發心血管疾病 |
| **Type IV：家族性高三酸甘油酯血症** | 肝臟 VLDL 過度分泌或清除不良 | **VLDL** | **TG 顯著升高** | 胰臟炎風險、關聯胰島素阻抗與第 2 型糖尿病 |
