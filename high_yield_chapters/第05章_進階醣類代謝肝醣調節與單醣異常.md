## 本章導讀與知識架構定位

進階醣類代謝是維持禁食期血糖恆定與紅血球抗氧化防禦的命脈。本章涵蓋四大核心主題：
1. **主題 5.1：糖質新生作用受質來源與四大繞道反應**（前驅原料乳酸/甘油/生糖胺基酸/丙酸、四大專屬繞道酵素、草醯乙酸穿梭、Cori 循環、酒精性低血糖機轉）
2. **主題 5.2：肝醣生合成、分解反應與跨組織荷爾蒙調控網絡**（肝醣磷解酶、去分支酵素雙功能、肝醣合成酶、cAMP-PKA 串聯級聯、肌肉 vs 肝臟差異）
3. **主題 5.3：肝醣儲積症全譜系（GSD Types 0 到 VII）**（Von Gierke、Pompe、Cori、Andersen、McArdle、Hers、Tarui 致病酵素、蓄積物與臨床表徵速查矩陣）
4. **主題 5.4：磷酸戊糖途徑（PPP）、單醣異常與多醣儲積病**（氧化支 G6PD 生成 NADPH、非氧化支轉酮酶需 TPP、蠶豆症、果糖代謝不耐症、半乳糖血症、黏多醣症、I-cell disease）

# 主題 5.1：糖質新生作用受質來源與四大繞道反應

### 重點一：核心高頻速查矩陣

#### 1. 糖質新生（Gluconeogenesis）四大繞道反應全覽
| 繞道關卡 | 催化酵素名稱 | 亞細胞定位與主要器官 | 所需輔基與能量消耗 | 異位調節與臨床重要性 |
| :---: | :--- | :--- | :--- | :--- |
| **Bypass 1a**<br>(繞過 PK) | **丙酮酸羧化酶**<br>(Pyruvate carboxylase, PC) | **粒線體基質**<br>(肝臟、腎臟皮質) | **需 生物素 (Biotin)**<br>**消耗 1 ATP** + $\text{CO}_2$ | **絕對依賴 Acetyl-CoA 異位活化！**（Acetyl-CoA 充足代表脂肪正在分解，刺激糖新生） |
| **Bypass 1b**<br>(繞過 PK) | **磷酸烯醇丙酮酸羧激酶**<br>(PEPCK) | **細胞質與粒線體** | **消耗 1 GTP**<br>(釋出 $\text{CO}_2$) | 受皮質醇（Cortisol）與升糖素強力誘導轉錄；受胰島素抑制 |
| **Bypass 2**<br>(繞過 PFK-1) | **果糖-1,6-二磷酸酶-1**<br>**(FBPase-1, 核心限速步)** | **細胞質** | 水解磷酸基，釋出 $\text{P}_i$<br>(不產生 ATP) | **受 AMP 與果糖-2,6-二磷酸 (F-2,6-BP) 強烈抑制**；受檸檬酸 (Citrate) 活化 |
| **Bypass 3**<br>(繞過 HK/GK) | **葡萄糖-6-磷酸酶**<br>**(Glucose-6-phosphatase)** | **內質網腔面 (ER Lumen)**<br>(**僅存在於肝臟與腎臟！**) | 水解磷酸基，釋出 $\text{P}_i$<br>(不產生 ATP) | **骨骼肌缺乏此酵素**，故肌糖原無法直接釋放葡萄糖至血液！**第 I 型肝醣儲積症缺陷標靶** |

#### 2. 草醯乙酸（OAA）穿出粒線體的接梭機制
- 粒線體內膜**沒有草醯乙酸轉運蛋白**！
- 解決方案：OAA 在粒線體內經**粒線體蘋果酸脫氫酶（mMDH）**還原為**蘋果酸（Malate）**，蘋果酸經由二羧酸轉運蛋白穿出至細胞質，再由**細胞質蘋果酸脫氫酶（cMDH）**重新氧化為 OAA，同時將還原當量帶出給細胞質生成 $\text{NADH}$（剛好供應糖新生第 6 步 GAPDH 逆反應所需！）。

#### 3. 酒精誘發嚴重低血糖（Ethanol-Induced Hypoglycemia）生化機轉
- 酒精（乙醇）在肝臟細胞質經**乙醇脫氫酶（ADH）**代謝為乙醛，乙醛在粒線體經**乙醛脫氫酶（ALDH）**代謝為乙酸。
- 兩步反應大量消耗 $\text{NAD}^+$，導致肝細胞內 **$\text{NADH}/\text{NAD}^+$ 比值極度飆升**！
- **後果（糖質新生三大前驅物全數被凍結阻斷）**：
  1. 高 $\text{NADH}$ 迫使丙酮酸全部轉化為**乳酸** $\to$ 丙酮酸耗竭，引發**乳酸酸中毒（Lactic acidosis）**。
  2. 高 $\text{NADH}$ 迫使草醯乙酸全部轉化為**蘋果酸** $\to$ OAA 耗竭。
  3. 高 $\text{NADH}$ 迫使二羥丙酮磷酸（DHAP）全部轉化為**甘油-3-磷酸** $\to$ 糖新生受質中斷，甘油轉向合成三酸甘油酯引發**脂肪肝**。
- 若酗酒者同時處於長期禁食（肝醣已耗竭），糖質新生遭徹底凍結，便會爆發致命性**重度低血糖**。

# 主題 5.2：肝醣生合成、分解反應與跨組織荷爾蒙調控網絡

### 重點一：核心高頻速查矩陣

#### 1. 肝醣合成分解酵素反應對照表
| 代謝方向 | 關鍵酵素名稱 | 催化之化學反應 | 產物或供體分子 | 臨床與遺傳疾病關聯 |
| :--- | :--- | :--- | :--- | :--- |
| **肝醣分解** | **肝醣磷解酶**<br>(Glycogen phosphorylase) | 磷酸解切斷 $\alpha(1 \to 4)$ 糖苷鍵（需 **PLP / 維生素 B6**） | 產出 **Glucose-1-phosphate (G-1-P)** | 催化至分支點前 4 個殘基處停住（極限糊精）；受 PKA 磷酸化活化 |
| | **去分支酵素**<br>(Debranching enzyme) | 雙功能酵素：<br>1. 轉移酶：移轉 3 個殘基至主鏈<br>2. $\alpha(1 \to 6)$ 葡萄糖苷酶：切除分支點 | 產出 **1 分子游離葡萄糖**（非 G-1-P！） | **第 III 型肝醣儲積症 (Cori 病)** 缺陷標靶；肝醣分解有 90% 產出 G-1-P，10% 產出游離葡萄糖 |
| **肝醣合成** | **UDP-葡萄糖焦磷酸化酶** | G-1-P + UTP $\to$ UDP-Glucose + $\text{PP}_i$ | **UDP-Glucose（活性葡萄糖供體）** | $\text{PP}_i$ 被無機焦磷酸酶迅速水解驅動反應不可逆 |
| | **肝醣素 (Glycogenin)** | 自身特定酪胺酸（Tyr-194）殘基進行自催化糖基化 | 形成 8 個葡萄糖殘基的引子（Primer） | 肝醣合成必須有引子存在，無法從頭合成 |
| | **肝醣合成酶**<br>(Glycogen synthase) | 將 UDP-Glc 轉移延長至非還原端，形成 $\alpha(1 \to 4)$ 鍵 | 延長直鏈肝醣 | 限速步驟；受 G-6-P 異位活化；**受 PKA 磷酸化失活**！ |
| | **分支酵素**<br>(Branching enzyme) | 剪切至少 6 個殘基，以 $\alpha(1 \to 6)$ 鍵接回鏈內部 | 創造多個非還原端，提高溶解度 | **第 IV 型肝醣儲積症 (Andersen 病)** 缺陷標靶 |

#### 2. 肌肉與肝臟肝醣調控的根本差異
- **肝臟肝醣**：主要受**升糖素（Glucagon）**與腎上腺素調控，擁有 G-6-Pase，目標是**維持全身血糖恆定**。
- **骨骼肌肝醣**：**完全沒有升糖素受體！缺乏 G-6-Pase！** 僅受**腎上腺素、AMP（肌肉疲勞）與 $\text{Ca}^{2+}$（肌肉收縮）**調控，分解出的 G-6-P 專供自身醣解供能，無法輸出提供全身。

# 主題 5.3：肝醣儲積症全譜系（GSD Types 0 到 VII）

### 重點一：核心高頻速查矩陣

| GSD 類型與俗名 | 缺陷酵素名稱 | 蓄積之肝醣組織與結構特徵 | 核心臨床鑑別症狀與生化檢驗 |
| :--- | :--- | :--- | :--- |
| **Type I：Von Gierke 病** | **葡萄糖-6-磷酸酶**<br>(Glucose-6-phosphatase) | 肝臟與腎臟；肝醣結構正常但量極大 | **重度空腹低血糖、嚴重乳酸血症（Lactic acidosis）、高尿酸血症（痛風）、高血脂、娃娃臉、顯著肝脾腫大**；給予升糖素後血糖不升但乳酸飆高 |
| **Type II：Pompe 病** | **溶小體酸性 $\alpha$-1,4-葡萄糖苷酶**<br>(Lysosomal $\alpha$-glucosidase / 酸性麥芽糖酶) | **溶小體（Lysosome）內**蓄積大量肝醣；心肌、骨骼肌受累 | **心臟肥大（Cardiomegaly）**、嬰兒期心衰竭夭折、肌無力；**血糖完全正常**（細胞質肝醣代謝完好）！ |
| **Type III：Cori / Forbes 病** | **去分支酵素**<br>(Debranching enzyme) | 肝臟與骨骼肌；蓄積**分支極短之異常外周極限糊精** | 輕度空腹低血糖、肝腫大、肌無力；**血乳酸正常**；給予升糖素在餐後血糖可升高，禁食時不升 |
| **Type IV：Andersen 病** | **分支酵素**<br>(Branching enzyme) | 肝臟與脾臟；蓄積**無分支、異常長鏈之纖維狀多醣**（Amylopectin 樣） | 異物免疫反應引發**幼年早期進行性肝硬化、門脈高壓**，多在 2~4 歲內死於肝衰竭 |
| **Type V：McArdle 病** | **肌肉型肝醣磷解酶**<br>(Myophosphorylase) | **僅骨骼肌**；肌肉肝醣量輕度增加 | **運動誘發劇烈肌肉疼痛痙攣、橫紋肌溶解、肌紅素尿症（茶色尿）、運動後血乳酸完全不升高**；血糖正常 |
| **Type VI：Hers 病** | **肝臟型肝醣磷解酶**<br>(Hepatic phosphorylase) | 僅肝臟；肝醣結構正常 | 輕度空腹低血糖、肝腫大；預後良好 |
| **Type VII：Tarui 病** | **肌肉型 PFK-1** | 骨骼肌與紅血球 | 類似 McArdle（運動肌無力），但伴隨溶血性貧血 |

# 主題 5.4：磷酸戊糖途徑（PPP）、單醣異常與多醣儲積病

### 重點一：核心高頻速查矩陣

#### 1. 磷酸戊糖途徑（HMP Shunt）雙階段特徵
- **氧化階段（不可逆，產出 NADPH）**：
  - 核心限速酵素：**葡萄糖-6-磷酸脫氫酶（G6PD）**。
  - 每分子 G-6-P 經兩次去氫反應產生 **2 分子 NADPH + 1 分子 $\text{CO}_2$ + 1 分子 5-磷酸核糖**。
  - 受 $\text{NADP}^+/\text{NADPH}$ 比值嚴密調節（NADPH 為強效競爭性抑制劑）。
- **非氧化階段（可逆，碳骨架洗牌）**：
  - 轉酮酶（Transketolase）：轉移 2 碳單元，**絕對依賴維生素 B1 輔酶 TPP**（紅血球轉酮酶活性檢測為診斷 B1 缺乏之金標準）。
  - 轉醛酶（Transaldolase）：轉移 3 碳單元。產物匯回 F-6-P 與 G-3-P。

#### 2. NADPH 的四大關鍵生理用途
1. **還原性生物合成**：脂肪酸生合成、膽固醇合成、類固醇荷爾蒙合成。
2. **維持細胞還原態穀胱甘肽（GSH）**：保護紅血球細胞膜對抗過氧化氫氧化壓力。
3. **呼吸爆發（Respiratory Burst）**：吞噬細胞 NADPH 氧化酶催化生成超氧陰離子殺菌。
4. **細胞色素 P450 系統**：肝臟藥物代謝解毒與固醇類羥化反應。

#### 3. 單醣遺傳代謝缺陷病對照表
| 疾病名稱 | 致病缺陷酵素名稱 | 體內積累之毒性基質 | 核心臨床表徵與鑑別診斷 |
| :--- | :--- | :--- | :--- |
| **本態性果糖尿症**<br>(Essential Fructosuria) | **果糖激酶**<br>(Fructokinase) | 果糖（Fructose）自尿液大量流失 | **良性無症狀！** 尿液還原糖試驗陽性但葡萄糖氧化酶試驗陰性 |
| **遺傳性果糖不耐症 (HFI)** | **醛縮酶 B**<br>(Aldolase B) | **1-磷酸果糖 (F-1-P) 於肝細胞大量堆積** | 斷奶攝取水果/蔗糖後發病：**F-1-P 蓄積耗竭細胞質游離無機磷（$\text{P}_i$），導致 ATP 衰竭，全面抑制糖質新生與肝醣分解，爆發致死性低血糖、黃疸、肝衰竭**；治療：嚴格戒絕果糖與蔗糖 |
| **半乳糖激酶缺乏症** | **半乳糖激酶**<br>(Galactokinase) | 半乳糖轉向醛醣還原酶生成**半乳糖醇 (Galactitol)** | **幼年早期晶狀體白內障（Cataract）**；無肝臟或神經毒性 |
| **典型半乳糖血症**<br>(Classic Galactosemia) | **半乳糖-1-磷酸尿苷轉移酶**<br>(**GALT**) | **1-磷酸半乳糖 (Gal-1-P) 及半乳糖醇** | 新生兒哺乳即發病：**發育遲緩、智能障礙、白內障、肝脾腫大、肝硬化、新生兒大腸桿菌敗血症**；治療：立即停母乳，換無乳糖大豆配方奶 |
