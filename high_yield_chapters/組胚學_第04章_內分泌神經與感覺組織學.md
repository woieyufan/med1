# 醫師國考一階段重點精華與修課手冊
## 組織與胚胎學 第 04 章：內分泌、神經與感覺組織學
### 科目：人體組織學 ｜ 醫學（一）Q31~Q43 必考核心

---

## 本章導讀與知識架構定位

內分泌與神經系統是人體調控體內恆定與傳遞高階資訊的兩大支配系統。考選部在此處出題側重於細胞的微觀染色特性、胞質特化細胞器與神經膠質細胞的發生與功能。核心高頻考點包括：腦下垂體前葉嗜酸/嗜鹼細胞分泌荷爾蒙、神經垂體赫令氏體（Herring bodies）、甲狀腺濾泡旁 C 細胞（降鈣素）、腎上腺皮質三帶（球狀、束狀、網狀帶）與髓質嗜鉻細胞、神經元型態分類（雙極神經元分佈特徵），以及中樞四大膠質細胞與周邊兩大膠質細胞的機能對照。

本章下轄三大核心主題：
1. **主題 4.1：內分泌腺體微細結構與特化分泌細胞**（腦下垂體腺垂體嗜酸/嗜鹼/嫌色細胞、神經垂體無髓纖維與赫令氏體、甲狀腺濾泡膠體與濾泡旁 C 細胞、副甲狀腺主細胞嗜酸細胞、腎上腺皮質三帶與髓質嗜鉻細胞）
2. **主題 4.2：神經元微細結構與型態學分類**（胞體尼氏體 Nissl bodies、軸突無尼氏體、樹突棘、多極/雙極/假單極神經元體內特化分佈、軸突順向逆向運輸）
3. **主題 4.3：神經膠質細胞（Neuroglia）全覽與髓鞘形成**（中樞四大膠質：星狀膠質細胞 BBB 足板、寡突膠質細胞中樞髓鞘、微膠質細胞巨噬、室管膜細胞 CSF；周邊兩大膠質：許旺細胞周邊髓鞘蘭氏結、節衛星細胞）

# 主題 4.1：內分泌腺體微細結構與特化分泌細胞

### 重點一：核心高頻速查矩陣

#### 1. 腦下垂體（Pituitary Gland / 垂體）組織學分區與細胞對照表
| 腺體大區 | 組織學次分區 | 包含細胞種類 | 胞質嗜色性與合成荷爾蒙 | 臨床重要生理意義 |
| :--- | :--- | :--- | :--- | :--- |
| **腺垂體**<br>**(Adenohypophysis)**<br>*(源自口腔外胚層 Rathke 氏囊)* | **遠側部**<br>**(Pars distalis)**<br>*(前葉主體)* | 1. **嗜酸性細胞 (Acidophils, ~40%)** | 橘紅色深染顆粒；分泌：<br>① **生長激素 (GH / 促生長素)**<br>② **催乳素 (PRL / 泌乳素)** | 嗜酸性腺瘤引發肢端肥大症（成人）或巨人症（兒童）；溢乳症 |
| | | 2. **嗜鹼性細胞 (Basophils, ~10%)** | 紫藍色顆粒；分泌促激素：<br>① **ACTH** (促腎上腺皮質素)<br>② **TSH** (促甲狀腺素)<br>③ **FSH** (促濾泡素)<br>④ **LH** (促黃體生成素) | 庫欣氏病（Cushing's disease，ACTH 腺瘤）；B-FLAT 口訣 |
| | | 3. **嫌色細胞 (Chromophobes, ~50%)** | 胞質淺染無顆粒 | 脫顆粒後的休止期細胞或幹細胞 |
| **神經垂體**<br>**(Neurohypophysis)**<br>*(源自間腦底神經外胚層)* | **神經部**<br>**(Pars nervosa)**<br>*(後葉主體)* | **無神經元胞體！**<br>由下丘腦下行之**無髓神經纖維軸突**、**垂體細胞 (Pituicytes)** 及血竇構成 | **赫令氏體 (Herring bodies)**：軸突終末膨大，儲存：<br>① **抗利尿激素 (ADH / Vasopressin)**（主要由視上核合成）<br>② **催產素 (Oxytocin)**（主要由室旁核合成） | **後葉不合成荷爾蒙，僅儲存並釋放下丘腦合成之神經荷爾蒙！** 垂體柄切斷引發中樞性尿崩症 |

#### 2. 甲狀腺與副甲狀腺微細組織學
- **甲狀腺濾泡（Thyroid Follicle）**：
  - **濾泡上皮細胞（Follicular cells）**：單層立方上皮，合成甲狀腺球蛋白（Tg）釋入濾泡腔儲存為嗜酸性**膠體（Colloid）**；TSH 刺激時細胞變柱狀，胞吞膠體水解釋放 **T3 與 T4**。
  - **濾泡旁細胞（Parafollicular cells / C 細胞）**：位於濾泡上皮細胞之間或濾泡間結締組織中；**衍生自外胚層神經脊（神經咽下體）**；**合成分泌「降鈣素 (Calcitonin)」**，抑制蝕骨細胞活性，降低血鈣。
- **副甲狀腺（Parathyroid Gland）**：
  - **主細胞（Chief cells）**：數量最多，體積較小，胞質淺染；**合成分泌「副甲狀腺素 (PTH)」**，刺激骨吸收與腎小管活化維生素 D，升高血鈣、降低血磷。
  - **嗜酸性細胞（Oxyphil cells）**：青春期後出現，體積較大，胞質充滿密集粒線體而強烈嗜酸性鮮紅；無明顯分泌機能（衰老退化表現）。

#### 3. 腎上腺皮質三大帶與髓質（國考必背分層對照）
| 組織解剖分層 | 組織學特徵與細胞排列 | 主要受控之調節因子 | 分泌之核心荷爾蒙類群 |
| :--- | :--- | :--- | :--- |
| **皮質球狀帶**<br>**(Zona glomerulosa, 15%)** | 緊貼被膜下；細胞較小呈**圓形細胞團或球狀拱環排列** | **血管收縮素 II (Ang II)** 及高血鉀 $\text{K}^+$ | **礦物皮質素：醛固酮 (Aldosterone)**<br>(保鈉保水排鉀排氫) |
| **皮質束狀帶**<br>**(Zona fasciculata, 75%)** | 最厚層；細胞較大呈**多面體，垂直排列成平行條索**；胞質富含脂滴，製片溶解呈泡沫狀（**海綿細胞 Spongiocytes**） | **ACTH** (促腎上腺皮質激素) | **糖皮質素：皮質醇 (Cortisol)**<br>(升血糖、抗發炎、抑制免疫) |
| **皮質網狀帶**<br>**(Zona reticularis, 10%)** | 最深層鄰接髓質；細胞較小，**排列呈不規則互相吻合的細胞索網**；含大量脂褐素顆粒 | **ACTH** 及 LH | **性激素：雄激素 (DHEA、雄烯二酮)** |
| **腎上腺髓質**<br>**(Adrenal medulla)** | **源自外胚層神經脊！相當於特化的交感神經節**；多面體**嗜鉻細胞 (Chromaffin cells)** 排列成團 | **交感節前神經纖維釋放之乙醯膽鹼 (ACh)** | **兒茶酚胺：腎上腺素 (Epinephrine, 80%)** 及 **正腎上腺素 (Norepinephrine, 20%)** |

# 主題 4.2：神經元微細結構與型態學分類

### 重點一：核心高頻速查矩陣

#### 1. 神經元型態學三大分類與體內特化分佈（必考鑑別題）
| 神經元形態分類 | 突起引出數目特徵 | 樹突與軸突幾何構型 | 人體內的代表性特化分佈場所（必背！） |
| :--- | :--- | :--- | :--- |
| **雙極神經元**<br>**(Bipolar neurons)** | **僅發出 2 個突起**<br>(1 條樹突 + 1 條軸突，自細胞體兩端分別引出) | 細胞體呈梭形，兩端各自引出一條長突起 | **僅特化分佈於「特殊感覺器官」**！包含：<br>1. **視網膜雙極細胞 (Retina)**<br>2. **嗅黏膜嗅上皮感覺神經元 (Olfactory)**<br>3. **內耳前庭神經節與耳蝸螺旋神經節神經元** |
| **假單極神經元**<br>**(Pseudounipolar)** | **從胞體僅引出 1 個突起**，隨後呈「T 字形」分為兩支 | 周邊突（功能相當於樹突感受器）+ 中樞突（軸突進入 CNS） | **所有「脊神經背根神經節 (DRG)」** 及 **大部分腦神經感覺神經節（如三叉神經節半月節）**！ |
| **多極神經元**<br>**(Multipolar neurons)** | **發出 1 個軸突與多條樹突**<br>(突起 $\ge 3$ 個) | 樹突分枝繁茂，胞體呈星形、錐體形或梨形 | **人體絕大多數神經元（佔 99% 以上！）**：大腦錐體細胞、小腦浦肯野細胞、**脊髓前角運動神經元**、側角自主神經節前神經元、**交感與副交感神經節細胞** |

# 主題 4.3：神經膠質細胞（Neuroglia）全覽與髓鞘形成

### 重點一：核心高頻速查矩陣

#### 1. 中樞神經系統四大膠質細胞 vs 周邊兩大膠質細胞
| 膠質細胞名稱 | 所在系統 | 細胞形態與微觀標誌 | 核心生理與病理功能 |
| :--- | :--- | :--- | :--- |
| **星狀膠質細胞**<br>**(Astrocyte)** | **CNS** | 體積最大、突起最多；分原漿型（灰質）與纖維型（白質）；**特徵性表現膠質纖維酸性蛋白 (GFAP)**！ | 1. 突起末端膨大形成**血管周足板（End-feet），完全包繞毛細血管形成「血腦障壁 (BBB)」重要組成**！<br>2. 調節細胞外 $\text{K}^+$ 濃度、攝取並回收神經傳導物（麩胺酸）；損傷後形成**膠質瘢痕 (Glial scar)** |
| **寡突膠質細胞**<br>**(Oligodendrocyte)** | **CNS** | 胞體較小，突起較少呈星射狀；胞質緻密 | **中樞神經系統「髓鞘（Myelin sheath）」形成細胞**！**單一寡突膠質細胞可發出多個突起，同時包裹多達 30~50 條軸突形成節段髓鞘**！多發性硬化症（MS）攻擊目標 |
| **小膠質細胞**<br>**(Microglia)** | **CNS** | 體積最小，突起細長有棘狀小突起；**源自中胚層造血系統（單核球–巨噬細胞系統）**！ | **中樞神經系統的「專職巨噬細胞」**！在發炎、創傷或感染時活化轉變為變形蟲狀阿米巴細胞，吞噬壞死細胞與抗原碎片 |
| **室管膜細胞**<br>**(Ependymal cell)** | **CNS** | 單層立方或低柱狀上皮樣細胞，頂端具微絨毛與纖毛；被膜覆蓋脈絡叢 | 襯貼在各腦室與脊髓中央管內表面；在側腦室、第三、第四腦室特化參與構成**「脈絡叢（Choroid plexus）」，專職分泌生成腦脊髓液 (CSF)**！ |
| **許旺細胞**<br>**(Schwann cell)** | **PNS** | 源自神經脊；包裹周邊神經軸突 | **周邊神經系統（PNS）「髓鞘形成細胞」**！**「單一許旺細胞僅能包裹形成一條軸突的一個節段髓鞘」**（與寡突膠質細胞不同！）；兩相鄰許旺細胞間形成**蘭氏結 (Node of Ranvier)** 介導跳躍傳導；引導神經纖維再生（形成 Büngner 帶） |
| **衛星細胞**<br>**(Satellite cell)** | **PNS** | 單層扁平或立方細胞 | 環繞包覆周邊神經節（如脊神經背根神經節、交感神經節）神經元胞體外周，提供營養支持與微環境絕緣 |

## 考選部歷屆魔鬼陷阱與抽換標靶

!!! warning "高頻陷阱重點防護（考試最易混淆點）"

    - **【雙極神經元分佈場所排除陷阱】**：
        - 雙極神經元極為罕見，**僅分佈於：視網膜、嗅上皮、內耳前庭與耳蝸神經節**！
        - 脊神經節（背根神經節 DRG）是**「假單極神經元」**！交感神經節細胞是**「多極神經元」**！

    - **【髓鞘形成細胞：中樞 vs 周邊】**：
        - **中樞神經系統 (CNS) 髓鞘**：由**寡突膠質細胞（Oligodendrocytes）**形成（單個細胞包裹多條軸突）。
        - **周邊神經系統 (PNS) 髓鞘**：由**許旺細胞（Schwann cells）**形成（單個細胞僅包裹一個節段軸突）。

    - **【腎上腺各層胚胎起源大陷阱】**：
        - **腎上腺皮質（球狀、束狀、網狀帶）衍生自「中胚層（Mesoderm）」**！
        - **腎上腺髓質（嗜鉻細胞）衍生自「外胚層神經脊（Neural crest）」**！

## 歷屆國考經典真題實戰解析

#### 【115 年 第一次 醫學（一） 第 41 題】
**下列何者的神經元（neuron）不屬於雙極神經元（bipolar neuron）？**
- (A) 嗅上皮（olfactory epithelium）
- (B) 視網膜（retina）
- (C) 內耳前庭神經節（vestibular ganglion）
- (D) 脊神經背根神經節（dorsal root ganglion）

**【正解】(D)**
**【逐項剖析】**
- **神經元形態分類與分佈剖析**：
  - 雙極神經元（Bipolar neuron）具有一個樹突和一個軸突，從細胞核兩端對稱發出，專一性集中在特殊感覺轉導器官：
    - **(A) 嗅上皮**：嗅覺感受細胞即為雙極神經元。
    - **(B) 視網膜**：連接感光細胞與神經節細胞的雙極細胞為典型雙極神經元。
    - **(C) 內耳前庭神經節與耳蝸螺旋神經節**：傳導平衡覺與聽覺的第一級神經元均為雙極神經元。
  - **(D) 正選**：**脊神經背根神經節（Dorsal root ganglion, DRG）**內部的感覺神經元在發育過程中兩個突起融合，形成自胞體引出單一幹再呈 T 字形分開的**「假單極神經元（Pseudounipolar neuron）」**，絕對不屬於雙極神經元！

#### 【114 年 第二次 醫學（一） 第 41 題】
**交感神經節（sympathetic ganglion）內的神經元，多屬於下列何種形態？**
- (A) 多極神經元（multipolar neuron）
- (B) 雙極神經元（bipolar neuron）
- (C) 假單極神經元（pseudounipolar neuron）
- (D) 無軸突神經元（anaxonic neuron）

**【正解】(A)**
**【逐項剖析】**
- **自律神經節神經元形態剖析**：
  - 交感神經節（包含椎旁神經節與椎前神經節）內部的神經元為交感節後神經元，其胞體發出數條至數十條繁茂的樹突接收來自中樞節前纖維的突觸傳入，並發出一條長軸突走向周邊效應器官。
  - 因此其在形態學上具有一個軸突與多個樹突，**標準屬於「多極神經元（Multipolar neuron）」**。故選 **(A)**。

#### 【114 年 第二次 醫學（一） 第 45 題】
**關於甲狀腺濾泡（thyroid follicle）構造和功能的敘述，下列何者正確？**
- (A) 濾泡上皮細胞（follicular cells）主要分泌降鈣素（calcitonin）
- (B) 濾泡腔內儲存的膠體（colloid）主要成分為甲狀腺球蛋白（thyroglobulin）
- (C) 濾泡旁細胞（parafollicular cells）由內胚層（endoderm）發育而來
- (D) 濾泡旁細胞分泌甲狀腺素（thyroxine, T4）

**【正解】(B)**
**【逐項剖析】**
- **甲狀腺細胞與產物剖析**：
  - **(A) 錯誤**：分泌降鈣素（Calcitonin）的是濾泡旁細胞（C 細胞），濾泡上皮細胞分泌的是甲狀腺素（T3/T4）。
  - **(B) 正確**：甲狀腺濾泡中央腔隙充滿均質嗜酸性膠體，其**主要化學成分即為濾泡上皮細胞合成分泌的高分子醣蛋白——甲狀腺球蛋白（Thyroglobulin, Tg）**。碘化酪胺酸殘基在此蛋白分子上偶聯組裝為 T3 與 T4 儲存。
  - **(C) 錯誤**：濾泡旁細胞（C 細胞）源自**外胚層「神經脊（Neural crest）」**，經第四咽囊神經咽下體遷入甲狀腺，非內胚層。
  - **(D) 錯誤**：濾泡旁細胞專一分泌降鈣素，不分泌甲狀腺素。故選 **(B)**。
