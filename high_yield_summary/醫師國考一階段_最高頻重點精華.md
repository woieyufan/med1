### 2. 脊髓三大主要傳導路徑（Spinal Tracts）與脊髓半切

| 傳導路徑 | 主要傳導感覺 / 功能 | 一級神經元 / 交叉水平 | 脊髓半切症候群（Brown-Séquard）受損表現 |
| :--- | :--- | :--- | :--- |
| **背柱內側丘系 (DCML)** | 意識性本體感覺、兩點辨別覺、震動覺 | 脊神經節 $\rightarrow$ **延腦薄束核/楔狀核交叉** $\rightarrow$ 丘腦 VPL | **同側**病灶平面以下：震動覺與本體感覺喪失 |
| **外側脊髓丘腦徑 (Spinothalamic)** | 痛覺、溫覺 | 脊神經節 $\rightarrow$ 進入脊髓後 **1~2 節段前聯合交叉** $\rightarrow$ 丘腦 VPL | **對側**病灶平面以下 1~2 節：痛溫覺喪失 |

### 3. 腦幹三大代表性缺血症候群（Brainstem Syndromes）

1. **Wallenberg 症候群（延腦背外側症候群）**：
   - **受損血管**：後下小腦動脈（PICA）或脊椎動脈（Vertebral a.）。
   - **核心徵象**：
     - 同側臉部痛溫覺喪失（三叉神經脊髓核受損）。
     - 對側軀幹肢體痛溫覺喪失（脊髓丘腦徑受損）。
     - 聲音沙啞、吞嚥困難、作嘔反射消失（疑核 Nucleus ambiguus 受損，CN IX, X）。
     - 眩暈、眼球震顫（前庭神經核受損）。
     - 同側 Horner 症候群（下行交感神經纖維受損：瞳孔縮小、眼瞼下垂、臉部無汗）。
   - **真題標籤**：115-1-med1-001, 114-2-med1-001, 113-1-med1-001。
2. **Weber 症候群（中腦腹側症候群）**：
   - **受損血管**：後大腦動脈（PCA）分枝。
   - **核心徵象**：同側動眼神經麻痺（眼瞼下垂、眼球偏外下、瞳孔散大）+ 對側肢體痙攣性偏癱（大腦腳皮質脊髓徑受損）。
3. **Millard-Gubler 症候群（橋腦腹外側症候群）**：
   - **核心徵象**：同側周邊型顏面麻痺（CN VII）+ 同側眼球不能外展（CN VI）+ 對側肢體偏癱（CST）。

## 模組三：生理學・心肺腎與酸鹼（每年必拿 20~25 分）

### 1. 心室壓力-容積循環（PV Loop）核心狀態判讀（Tier 1）

```
  心室壓力 (mmHg)
    ▲
    │         C (主動脈瓣開啟) ───────── D (主動脈瓣關閉, ESV)
    │         │                          │
    │         │ 等容收縮                 │ 等容舒張
    │         │                          │
    │         B (二尖瓣關閉, EDV) ────── A (二尖瓣開啟)
    └────────────────────────────────────────► 心室容積 (mL)
```

- **四瓣開關定位點**：
  - **A 點**：二尖瓣開啟（充盈期開始）。
  - **B 點**：**二尖瓣關閉（第一心音 $S_1$ 產生，此處容積為舒張末期容積 EDV）**。
  - **C 點**：主動脈瓣開啟（射血期開始）。
  - **D 點**：**主動脈瓣關閉（第二心音 $S_2$ 產生，此處容積為收縮末期容積 ESV）**。
- **PV Loop 形態改變核心法則**：
  1. **前負荷增加 (Increased Preload)**：B 點右移，EDV 增加，心搏量 SV 增加，PV Loop 變寬。
  2. **後負荷增加 (Increased Afterload)**：CD 段上移，主動脈瓣較晚開啟、較早關閉，ESV 增加，SV 下降，PV Loop 變高變窄。
  3. **心肌收縮力增加 (Increased Inotropism)**：收縮末期壓力容積線（ESPVR）斜率變陡，D 點左移，ESV 顯著降低，SV 增加，射血分率 EF 增加。
- **歷屆真題**：115-1-med1-060, 114-1-med1-058, 113-2-med1-059。

| **Step 1** | **己糖激酶 (Hexokinase)**：組織分佈廣，低 $K_m$（親和力高），低 $V_{\max}$，受 G6P 反饋抑制。<br>**葡萄糖激酶 (Glucokinase)**：肝臟與胰島 $\beta$ 細胞，高 $K_m$，高 $V_{\max}$，受胰島素誘導，不受 G6P 抑制。 | **葡萄糖-6-磷酸酶 (G6Pase)** | G6Pase 僅存在於肝臟與腎臟內質網；**此酵素缺乏為第 I 型肝醣儲積症 (von Gierke disease)**。 |

### 2. 篩檢工具評估公式與盛行率效應大矩陣

```
                     黃金標準 真病 (+)     黃金標準 無病 (-)
篩檢結果 陽性 (+)          a (TP)                b (FP)           => 篩檢陽性總數 (a + b)
篩檢結果 陰性 (-)          c (FN)                d (TN)           => 篩檢陰性總數 (c + d)
                        ───────               ───────
                        患病總數               健康總數
                        (a + c)               (b + d)
```

- **敏感度 (Sensitivity)**：真病者中篩檢為陽性之機率：
  $$\text{Sensitivity} = \frac{a}{a+c} = \frac{TP}{TP+FN}$$
- **特異度 (Specificity)**：健康者中篩檢為陰性之機率：
  $$\text{Specificity} = \frac{d}{b+d} = \frac{TN}{FP+TN}$$
- **陽性預測值 (PPV)**：篩檢陽性者中真正有病之機率：
  $$\text{PPV} = \frac{a}{a+b}$$
- **盛行率對篩檢指標的影響（國考每年必考）**：
  1. 敏感度與特異度是篩檢工具的內在固有屬性，**完全不受疾病盛行率高低改變**。
  2. 當疾病盛行率（Prevalence）上升時：**陽性預測值 (PPV) 顯著上升**，陰性預測值 (NPV) 輕微下降。
  3. 當疾病盛行率下降時：**陰性預測值 (NPV) 上升**，陽性預測值 (PPV) 大幅下降（偽陽性比例增加）。
