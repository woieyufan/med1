## 系統核心特色

1. **章節全覆蓋（82/82 Chapters 100% Complete）**：九大基礎科目全部完工，無缺漏、無殘缺，章章具備國考核心考點、記憶口訣、易錯陷阱與真題對照。
2. **跨學科臨床思維鏈（Cross-Discipline Chains）**：串聯「解剖/胚胎 $\to$ 生理/生化 $\to$ 病理 $\to$ 藥理」，徹底破解臨床題組與跨科連鎖陷阱。
3. **離線無憂與雙格式交付**：本 MkDocs 靜態網站可於本地完全離線高速瀏覽與全文即時搜尋；另提供 82 個章節之微軟 Word (`.docx`) 與 Markdown (`.md`) 實體文檔及全科目合訂本。
