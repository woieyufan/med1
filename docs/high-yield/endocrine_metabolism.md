# 內分泌與新陳代謝跨學科高頻考點整合

內分泌系統貫穿下丘腦-垂體-靶腺軸負回饋調節、醣類脂質胺基酸三大營養素代謝途徑、糖尿病與甲狀腺病理，以及臨床內分泌代謝藥物。

---

## 跨學科整合思維鏈

```
[解剖/組胚] 垂體門脈系統 ──► 垂體前葉 (腺體外胚層 Rathke囊) vs 後葉 (神經外胚層)
   │
   ▼
[生理/生化] 負回饋軸線 (TRH-TSH-T3/T4, CRH-ACTH-Cortisol) ──► 胰島素酪胺酸激酶受體 ──► 脂質/蛋白質合成
   │
   ▼
[病理] 糖尿病 (微血管玻璃樣變, 腎球 Kimmelstiel-Wilson 結節) ──► 庫欣氏症 ──► 甲狀腺乳突癌
   │
   ▼
[藥理] 降血糖藥 (Metformin, SGLT2i, GLP-1 RA, DPP-4i) ──► 甲狀腺 (PTU, Methimazole) ──► 類固醇
```

## 降血糖藥物作用靶點、體重效應與器官保護對照表

| 藥物大類 | 代表藥物 | 核心降糖分子機轉 | 體重效應 | 心腎保護與國考關鍵特性 |
| :--- | :--- | :--- | :--- | :--- |
| **雙胍類 (Biguanides)** | **Metformin (二甲雙胍)** | 活化 AMPK，抑制肝臟糖質新生；增加周邊組織對胰島素敏感度 | 輕度減輕或中性 | **2型糖尿病第一線首選**；單用不引起低血糖；最嚴重併發症為**乳酸中毒**（eGFR $<30$ 禁用） |
| **SGLT2 抑制劑** | **Empagliflozin, Dapagliflozin** | 抑制腎近曲小管 SGLT2，阻斷葡萄糖重吸收，尿糖排泄 | **明顯減重 ($\downarrow$)** | **顯著降低心衰竭再住院率及延緩 CKD 惡化**；注意生殖泌尿道感染與正常血糖酮酸中毒 (euDKA) |
| **GLP-1 受體促效劑** | **Semaglutide, Liraglutide** | 葡萄糖依賴性促進胰島素分泌、抑制昇糖素、延緩胃排空、抑制下丘腦食慾 | **顯著減重 ($\downarrow\downarrow$)** | **顯著降低主要心血管不良事件 (MACE)**；注意腸胃道噁心嘔吐；甲狀腺髓質癌 (MTC) 病史禁用 |
| **DPP-4 抑制劑** | **Sitagliptin, Linagliptin** | 抑制二肽基肽酶-4，延緩內源性 GLP-1 降解 | 體重中性 | 單用不引起低血糖；副作用極少；**Linagliptin 經膽道排泄，腎功能不全者無需調整劑量** |
| **磺醯尿素類 (Sulfonylureas)** | **Glimepiride, Gliclazide** | 阻斷胰島 $\beta$ 細胞 ATP 敏感性鉀通道 ($K_{ATP}$)，促使細胞去極化鈣內流釋放胰島素 | **增加體重 ($\uparrow$)** | **極易誘發低血糖**；老年人及腎功能低下者慎用 |
| **噻唑烷二酮類 (TZDs)** | **Pioglitazone** | 結合核受體 PPAR-$\gamma$，調控脂肪生成基因，改善胰島素阻抗 | **增加體重 ($\uparrow$)** | 引起水鈉滯留，**NYHA III/IV 級心衰竭患者絕對禁用**；長期使用可能增加骨折風險 |
