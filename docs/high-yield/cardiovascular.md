# 心血管系統跨學科高頻考點整合

心血管系統橫跨人體解剖學、心臟胚胎發育、心血管生理學、心血管病理學與心血管藥理學，是醫師國考一階段平均題數最高、串聯最緊密的系統。

---

## 跨學科整合思維鏈

```
[解剖] 冠狀動脈走向與支配區 (LAD, LCx, RCA) ──► 竇房結/房室結血供
   │
   ▼
[組胚] 心管彎曲旋轉 ──► 動脈幹螺旋分隔異常 (法洛氏四重症, 大動脈轉位)
   │
   ▼
[生理] 心肌動作電位 (Phase 0~4) 與壓力-容積環 (PV Loop: 前負荷、後負荷、收縮力)
   │
   ▼
[病理] 內皮損傷 ──► 動脈粥狀硬化斑塊破裂 ──► 冠脈血栓 ──► 急性心肌梗塞 (凝固性壞死)
   │
   ▼
[藥理] 抗心肌缺血 (硝酸鹽+β-blocker) ──► 心衰竭延緩死亡率四巨頭 (ARNI+BB+MRA+SGLT2i)
```

## 冠狀動脈走向、心肌梗塞導程與臨床併發症對照表

| 冠狀動脈分枝 | 供血心臟結構與傳導系統 | 心電圖異常導程（ST段升高） | 典型併發症與處置陷阱 |
| :--- | :--- | :--- | :--- |
| **左前降支 (LAD)**<br>*(Widow Maker)* | 左心室前壁、心尖部、心室間隔前 $2/3$、前乳頭肌 | **$V_1 \sim V_4$**（前壁/間隔部心梗） | 最常見心肌梗塞死因；心因性休克、心室間隔破裂穿孔、左心室動脈瘤形成 |
| **左迴旋支 (LCx)** | 左心室側壁、後側壁、竇房結（約 40%） | **I, aVL, $V_5, V_6$**（側壁心梗） | 左心室功能受損 |
| **右冠狀動脈 (RCA)** | 左心室下壁、右心室、房室結（AV node, 90% 右優勢型）、竇房結（60%） | **II, III, aVF**（下壁心梗） | **右心室心肌梗塞**（血壓暴跌但肺音乾淨！**絕對禁用硝酸甘油/利尿劑**，需全力補液維持右室前負荷）；房室傳導阻滯（AV block） |

## 心臟壓力-容積環（Pressure-Volume Loop）參數變動法則

| 血行動力學介入條件 | 舒張末期容積 (EDV) | 收縮末期容積 (ESV) | 心搏輸出量 (SV) | 脈壓差 (Pulse Pressure) | PV 環形狀變化特徵 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **增加前負荷 (Preload)**<br>*(如大量快速輸液)* | **$\uparrow$ 顯著上升** | 不變 | **$\uparrow$ 增加** | $\uparrow$ 增加 | PV 環向**右側加寬**，右下角右移 |
| **增加後負荷 (Afterload)**<br>*(如主動脈狹窄、突發高血壓)* | 不變 | **$\uparrow$ 顯著上升** | **$\downarrow$ 減少** | 不變或減少 | PV 環向**上方變高、寬度變窄** |
| **增強心肌收縮力 (Inotropy)**<br>*(如使用多巴酚丁胺 Dobutamine)* | 不變 | **$\downarrow$ 顯著下降** | **$\uparrow$ 增加** | $\uparrow$ 增加 | ESPVR 斜率變陡，PV 環向**左側加寬** |
| **心肌衰竭 (Heart Failure)** | **$\uparrow$ 上升** | **$\uparrow$ 顯著上升** | **$\downarrow$ 減少** | $\downarrow$ 下降 | PV 環**向右上方偏移且寬度嚴重縮窄** |

## 心衰竭（HFrEF）降低長期死亡率四大基石藥物（Fantastic Four）

| 藥物分類 | 代表藥物 | 核心藥理機轉 | 國考必考考點與禁忌 |
| :--- | :--- | :--- | :--- |
| **1. ARNI** | **Sacubitril / Valsartan** | 腦啡肽酶（Neprilysin）抑制劑 + 血管張力素受體拮抗劑（$AT_1$ 阻斷） | 抑制胜肽降解，增加心鈉素（ANP/BNP）保護作用；**禁與 ACEI 併用（需間隔 36 小時以防嚴重血管性水腫）** |
| **2. 心臟專一性 $\beta$-Blockers** | **Carvedilol, Bisoprolol, Metoprolol succinate** | 阻斷交感神經高活性毒性，抗心室重塑，預防惡性心律不整 | 必須在**病人血行動力學穩定、無急性肺水腫**時自極低劑量開始滴定；**不可在急性失代償期猛然增量** |
| **3. 礦物皮質素受體拮抗劑 (MRA)** | **Spironolactone, Eplerenone** | 競爭性阻斷集尿管醛固酮受體，保鉀排鈉，強效抑制心肌間質纖維化 | 主要副作用為**高血鉀症**；Spironolactone 具抗雄性素活性易致**男性女乳症**，Eplerenone 專一性高副作用少 |
| **4. SGLT2 抑制劑** | **Dapagliflozin, Empagliflozin** | 抑制腎臟近曲小管 SGLT2，排糖排鈉，降低心臟前負荷與後負荷 | 不論病患有無糖尿病均可顯著降低心血管死亡與心衰再住院率；注意**泌尿生殖道黴菌感染**與正常血糖酮酸中毒（euDKA） |
