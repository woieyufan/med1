# 呼吸系統跨學科高頻考點整合

呼吸系統涵蓋呼吸道解剖、呼吸力學、氣體交換、限制性與阻塞性肺疾病病理，以及氣喘和慢性阻塞性肺病（COPD）的藥理學治療。

---

## 跨學科整合思維鏈

```
[解剖/組胚] 氣管分枝 (隆突 Carina 異物易入右主支氣管) ──► Type II 肺泡細胞分泌表面張力素 (Surfactant, 35週成熟)
   │
   ▼
[生理] 肺容量動態 ($FEV_1$, FVC) 與通氣/灌流比 ($V_A/Q$ mismatch, 肺尖 high, 肺底 low)
   │
   ▼
[病理] 氣道慢性發炎 ──► 阻塞性 (COPD, 氣喘) vs 限制性肺病 (特發性肺纖維化, 矽肺症) ──► 肺癌 (腺癌 EGFR/ALK 最多)
   │
   ▼
[藥理] 氣管擴張劑 (SABA/LABA, 抗膽鹼 LAMA) + 抗發炎 (吸入性類固醇 ICS) + 標靶化療 (Osimertinib, Pembrolizumab)
```

## 阻塞性 vs 限制性肺疾病全面鑑別對照表

| 鑑別參數指標 | 阻塞性肺疾患 (Obstructive Lung Disease)<br>*(COPD, 氣喘, 支氣管擴張症)* | 限制性肺疾患 (Restrictive Lung Disease)<br>*(特發性肺纖維化, 脊柱側彎, 肥胖)* |
| :--- | :--- | :--- |
| **一秒用力吐氣容積 ($FEV_1$)** | **顯著下降 ($\downarrow\downarrow$)** | 輕度下降或正常 ($\downarrow$ 或 Normal) |
| **用力肺活量 (FVC)** | 正常或輕度下降 | **顯著下降 ($\downarrow\downarrow$)** |
| **一秒率 ($FEV_1 / FVC$)** | **$< 70\%$（核心診斷黃金標準）** | **正常或上升（$\ge 80\%$）** |
| **功能殘氣量 (FRC) 與殘容積 (RV)** | **顯著上升 ($\uparrow\uparrow$)（空氣滯留 Air-trapping）** | **顯著下降 ($\downarrow\downarrow$)** |
| **肺總量 (TLC)** | 上升 ($\uparrow$)（桶狀胸 Barrel chest） | **顯著下降 ($\downarrow\downarrow$)（肺擴張受限）** |
| **典型一氧化碳擴散量 ($DL_{CO}$)** | 肺氣腫顯著下降；慢性支氣管炎/氣喘正常 | 肺間質纖維化顯著下降；胸廓外異常者正常 |

## 肺癌組織病理學、致癌基因與臨床特徵

| 組織學分型 | 好發部位與性別/吸菸關係 | 典型組織鏡檢特徵 | 關鍵基因突變與臨床處置 |
| :--- | :--- | :--- | :--- |
| **肺腺癌 (Adenocarcinoma)** | **周邊部 (Peripheral)**；女性、**非吸菸者**最常見肺癌 | 腺體結構（Glandular）、黏液分泌；TTF-1, Napsin A 陽性 | **EGFR 突變**（標靶藥：Osimertinib）、**ALK 重排**（標靶藥：Alectinib）、ROS1、KRAS |
| **鱗狀細胞癌 (Squamous Cell Ca)** | **中央肺門部 (Central)**；**與重度吸菸極度相關** | **角化珠 (Keratin pearls)**、細胞間橋（Intercellular bridges）；p40, p63 陽性 | 易造成空洞化（Cavitation）；常異位分泌 **PTHrP 導致高血鈣症** |
| **小細胞肺癌 (Small Cell Lung Ca)** | **中央肺門部 (Central)**；**與吸菸極度相關** | 圓形小藍細胞、**核質比極高、染色質胡椒鹽狀**；Synaptophysin, Chromogranin A 陽性 | 神經內分泌癌，惡性度極高；常併發 **SIADH、庫欣氏症（ACTH）、Lambert-Eaton 肌無力**；首選化放療 |
