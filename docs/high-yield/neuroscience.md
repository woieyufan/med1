# 神經科學與中樞系統跨學科高頻考點整合

神經科學結合脊髓白質傳導束、12 對腦神經病變、突觸神經傳導物質、腦血管中風病理、神經退化性疾患，以及中樞神經藥物。

## 跨學科整合思維鏈

```
[神經解剖] 脊髓三大傳導束 (皮質脊髓束, 背柱內側丘系, 脊髓丘腦束) ──► 12對腦神經走向與出顱孔
   │
   ▼
[組胚/生理] 神經管與神經脊演化 ──► 動作電位傳導 ──► 突觸神經傳導物 (ACh, 5-HT, DA, GABA, Glu)
   │
   ▼
[病理] 腦血管中風 (MCA 偏癱失語) ──► 神經退化 (阿茲海默 Aβ/Tau, 巴金森 Lewy body α-synuclein)
   │
   ▼
[藥理] 抗癲癇藥 (Na 通道阻斷) ──► 巴金森用藥 (L-Dopa/Carbidopa) ──► 抗精神病藥 (D2 阻斷) ──► 抗憂鬱 (SSRI)
```

## 脊髓半切症候群（Brown-Séquard Syndrome）病理生理定位

當脊髓某節段發生半側橫斷性損傷（例如刺傷、腫瘤壓迫）：

| 脊髓受損傳導束路徑 | 傳導之感覺/運動功能 | 纖維交叉部位 | 臨床症狀體徵分佈 |
| :--- | :--- | :--- | :--- |
| **皮質脊髓側束 (Lateral Corticospinal Tract)** | 同側隨意運動控制（上運動神經元 UMN） | **延腦錐體交叉 (Medullary Pyramids)** | **受損節段平面以下：同側痙攣性偏癱**、Babinski sign 陽性、深腱反射亢進 |
| **背柱-內側丘系 (Dorsal Columns: Gracilis/Cuneatus)** | 意識性本體感覺、兩點辨別覺、振動覺 | **延腦薄束/楔束核交叉** | **受損節段平面以下：同側本體感覺、振動覺喪失** |
| **脊髓丘腦側束 (Lateral Spinothalamic Tract)** | 痛覺與溫覺傳導 | **進入脊髓後於前連合處交叉（1~2節段內交叉）** | **受損節段平面 1~2 節以下：對側痛溫覺喪失** |
| **受損平面前角細胞 (Anterior Horn)** | 下運動神經元 (LMN) | 無交叉 | **受損節段平面水平：同側下運動神經元弛緩性麻痺**、肌肉萎縮、反射消失 |

## 12 對腦神經出顱孔道、功能與典型損傷體徵

| 腦神經編號與名稱 | 通過之顱底孔道 | 支配主要功能 | 損傷後特異性神經體徵 |
| :--- | :--- | :--- | :--- |
| **CN I 嗅神經** | 篩骨篩孔 (Cribriform plate) | 嗅覺 | 嗅覺喪失 |
| **CN II 視神經** | 視神經管 (Optic canal) | 視覺、瞳孔光反射傳入支 | 患側單眼全盲、傳入型瞳孔障礙 (RAPD / Marcus Gunn pupil) |
| **CN III 動眼神經** | 眶上裂 (Superior orbital fissure) | 提上瞼肌、上/下/內直肌、下斜肌、縮瞳副交感 | **眼向下外方偏斜（Down and out）**、上眼瞼下垂、瞳孔散大固定 |
| **CN IV 滑車神經** | 眶上裂 (SOF) | 上斜肌（使眼球向下內旋） | 走樓梯下樓困難；頭向健側傾斜以代償複視 |
| **CN V 三叉神經** | $V_1$ 眶上裂；$V_2$ 圓孔 (Rotundum)；$V_3$ 卵圓孔 (Ovale) | 面部感覺、$V_3$ 支配咀嚼肌、角膜反射傳入支 | 面部麻木、張口時**下頜偏向患側**（外翼肌失神經） |
| **CN VI 外旋神經** | 眶上裂 (SOF) | 外直肌（眼球外展） | **患側眼無法外展，出現水平內斜視複視** |
| **CN VII 顏面神經** | 內耳門 $\to$ 莖乳孔 (Stylomastoid foramen) | 顏面表情肌、舌前 2/3 味覺、淚腺/下頜腺分泌、角膜反射傳出支 | **貝爾氏麻痺 (Bell's palsy)**：同側整側臉癱（含額頭皺紋消失、無法閉眼、嘴角歪向健側） |
| **CN VIII 前庭耳蝸** | 內耳門 (Internal acoustic meatus) | 聽覺與平衡覺 | 患側感音性聽力受損、耳鳴、眩暈 |
| **CN IX 舌咽神經** | 頸靜脈孔 (Jugular foramen) | 舌後 1/3 感覺與味覺、頸動脈竇頸動脈體化學/壓力感受傳入、咽反射傳入支 | 嘔吐反射（Gag reflex）傳入喪失、舌後味覺喪失 |
| **CN X 迷走神經** | 頸靜脈孔 (Jugular foramen) | 咽喉內在肌、胸腹腔內臟副交感、咽反射傳出支、主動脈弓受體傳入 | **懸雍垂（Uvula）偏向健側**；聲音嘶啞（喉返神經損傷）、吞嚥困難 |
| **CN XI 副神經** | 頸靜脈孔 (Jugular foramen) | 胸鎖乳突肌 (SCM)、斜方肌 | **向患側聳肩無力**、頭轉向對側阻力減弱 |
| **CN XII 舌下神經** | 舌下神經管 (Hypoglossal canal) | 舌內在與外在肌（除腭舌肌外） | **伸舌時舌尖偏向患側**（頦舌肌推向患側無對抗） |
