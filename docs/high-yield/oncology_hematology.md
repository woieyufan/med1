# 血液腫瘤與精準醫學跨學科高頻考點整合

血液與腫瘤系統橫跨造血組織胚胎學、原癌基因與抑癌基因分子機轉、貧血與白血病淋巴瘤病理學，以及化療標靶免疫檢查點抑制劑。

---

## 跨學科整合思維鏈

```
[組胚/解剖] 骨髓造血幹細胞 (CD34+) ──► 淋巴結架構 (濾泡 B cell, 副皮質 T cell) ──► 脾臟紅髓過濾
   │
   ▼
[生化/生理] 葉酸/維生素 B12 一碳循環 ──► 凝血瀑布 (內源 aPTT vs 外源 PT) ──► 原癌/抑癌基因 (p53, Rb)
   │
   ▼
[病理] 貧血 (小球缺鐵 vs 大球巨幼) ──► 白血病 (AML Auer rods, CML t(9;22)) ──► 淋巴瘤 (RS 細胞)
   │
   ▼
[藥理] 抗凝血藥 (Heparin, Warfarin, DOAC) ──► 抗代謝化療 (MTX, 5-FU) ──► 標靶免疫 (Imatinib, PD-1)
```

## 貧血紅白血球指數與骨髓抹片鑑別對照表

| 貧血分類大項 | 疾病名稱 | 紅血球平均容積 (MCV) | 血清鐵 (Iron) / 儲鐵蛋白 (Ferritin) | 關鍵病理機制與鑑別標誌 |
| :--- | :--- | :--- | :--- | :--- |
| **小球性低色素貧血 (Microcytic)**<br>*($\text{MCV} < 80\text{ fL}$)* | **缺鐵性貧血 (IDA)** | 下降 ($\downarrow$) | 血清鐵低下、**Ferritin 顯著低下**、TIBC 上升 | 全球最常見貧血；慢性失血（腸胃道潰瘍/腫瘤、經血過多）；紅血球中央蒼白區擴大 |
| | **地中海型貧血 (Thalassemia)** | **極度低下 ($\downarrow\downarrow$)** | 血清鐵正常或升高、**Ferritin 正常或升高** | 珠蛋白鏈合成缺陷（$\alpha$ 或 $\beta$）；**靶細胞 (Target cells)**；血紅素電泳異常 |
| | **慢性病性貧血 (ACD)** | 下降或正常 | 血清鐵低下、**Ferritin 升高 ($\uparrow$)**、TIBC 下降 | 慢性發炎刺激肝臟釋放 **鐵調素 (Hepcidin)**，抑制巨噬細胞釋鐵及腸道鐵吸收 |
| | **鐵芽球性貧血 (Sideroblastic)** | 下降或正常 | 血清鐵升高、**Ferritin 顯著升高** | 原紫質（Protoporphyrin）合成障礙（ALAS 缺陷、鉛中毒、維生素 $B_6$ 缺乏）；骨髓可見**環形鐵芽球 (Ring sideroblasts)** |
| **大球性巨幼細胞貧血 (Macrocytic)**<br>*($\text{MCV} > 100\text{ fL}$)* | **維生素 $B_{12}$ 缺乏貧血** | **顯著升高 ($\uparrow\uparrow$)** | 正常或偏高 | 一碳循環受阻，DNA 合成障礙但 RNA 正常；**嗜中性白血球核分葉過多 (Hypersegmented neutrophils, $\ge 6$葉)**；**併發亞急性聯合脊髓變性 (SCD，本體感覺共濟失調)**；MMA 與 Homocysteine 均升高 |
| | **葉酸 (Folate) 缺乏貧血** | **顯著升高 ($\uparrow\uparrow$)** | 正常 | 鏡檢同樣見嗜中性白血球核分葉過多；**神經學症狀正常**；僅 Homocysteine 升高，MMA 正常 |

## 白血病與淋巴瘤細胞遺傳學易位基因與標靶藥物

| 血液腫瘤名稱 | 特徵性染色體易位 | 形成之融合基因 / 癌基因 | 關鍵病理鏡檢特徵 | 臨床第一線標靶藥物 |
| :--- | :--- | :--- | :--- | :--- |
| **慢性骨髓性白血病 (CML)** | **$t(9;22)(q34;q11)$**<br>*(費城染色體 Ph)* | **BCR-ABL**（持續活化之酪胺酸激酶） | 骨髓全系增生，周邊血見各階段幼稚白血球；嗜鹼性球增多 | **Imatinib (格列衛)**、Dasatinib（BCR-ABL 酪胺酸激酶抑制劑 TKI） |
| **急性前骨髓性白血病 (APL, AML M3)** | **$t(15;17)(q22;q12)$** | **PML-RARA**（維生素A酸受體融合） | 原始細胞內充斥大量 **Auer rods (柴捆狀 Auer rods)**；極易誘發致命性 **DIC** | **全反式維生素A酸 (ATRA)** + 三氧化二砷 ($As_2O_3$) 誘導分化 |
| **伯基特淋巴瘤 (Burkitt Lymphoma)** | **$t(8;14)(q24;q32)$** | **c-MYC** 轉位至 Ig 重鏈基因下游高表達 | 腫瘤細胞高度增殖，組織呈典型**“星空狀”外觀 (Starry sky pattern)**；與 EB 病毒相關 | 密集高劑量化療（Cyclophosphamide, Rituximab） |
| **濾泡性淋巴瘤 (Follicular Lymphoma)** | **$t(14;18)(q32;q21)$** | **BCL-2** 轉位至 Ig 重鏈強啟動子過度表達 | **抗凋亡蛋白 BCL-2 過度表達**，抑制生發中心 B 細胞程序性死亡 | 觀察或 Rituximab（抗 CD20 單株抗體） |
| **何杰金氏淋巴瘤 (Hodgkin Lymphoma)** | 無特定易位 | CD15+, CD30+ 陽性腫瘤巨細胞 | **Reed-Sternberg (RS) 細胞（貓頭鷹雙核眼睛外觀 Owl-eyes）**；發炎背景細胞為其主體 | ABVD 化療處置；Brentuximab vedotin (抗 CD30 ADC) |
