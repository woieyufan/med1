# 消化與肝膽胰系統跨學科高頻考點整合

消化系統橫跨腹部血管神經解剖、胃腸消化荷爾蒙生理、膽紅素與肝醣代謝、肝硬化與消化道腫瘤病理，以及消化性潰瘍與腸道用藥。

---

## 跨學科整合思維鏈

```
[解剖/胚胎] 腹腔幹/腸系膜上/下動脈 ──► 門脈-體循環側支吻合 ──► 中腸生理性旋轉 (腸扭轉)
   │
   ▼
[生理/生化] 胃酸壁細胞分泌 ($H^+/K^+$ ATPase) ──► 膽紅素代謝 (間接 vs 直接) ──► 尿素循環
   │
   ▼
[病理] 幽門螺旋桿菌 ──► 慢性萎縮性胃炎 ──► 腸化生 ──► 腺癌；肝硬化 ──► 門脈高壓
   │
   ▼
[藥理] 質子泵抑制劑 (PPI: Omeprazole) ──► $H_2$ 阻斷劑 ──► 止吐劑 ($5-HT_3$ Ondansetron) ──► 瀉劑
```

## 門脈高壓三大門脈-體循環吻合處解剖與臨床徵候

| 門脈高壓吻合部位 | 門靜脈系統引流支 (高壓側) | 體靜脈系統回流支 (低壓側) | 臨床曲張表現與致命危險 |
| :--- | :--- | :--- | :--- |
| **食道下段 (Lower Esophagus)** | **胃左靜脈 (Left gastric vein)** | **奇靜脈 (Azygos vein)** | **食道靜脈曲張破裂 (Esophageal varices)**：致死性大吐血，首選內視鏡結紮 + Terlipressin/Octreotide |
| **臍周圍 (Periumbilical)** | **副臍靜脈 (Paraumbilical vein)** | **腹壁淺靜脈與腹壁下靜脈** | **海蛇頭 (Caput medusae)**：肚臍周圍怒張迂曲之表淺靜脈 |
| **直腸下段 (Lower Rectum)** | **直腸上靜脈 (Superior rectal vein)** | **直腸中與直腸下靜脈**（入髂內靜脈） | **直腸靜脈曲張 (Rectal varices)**：大便鮮血（需與一般痔瘡區分） |

## 高膽紅素血症與黃疸病因機轉鑑別

| 黃疸疾病類型 | 直接膽紅素 (結合型, DB) | 間接膽紅素 (未結合型, IB) | 尿中膽紅素 | 尿中膽素原 (Urobilinogen) | 關鍵分子機轉與臨床表現 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **溶血性黃疸 (溶血貧血)** | 正常 | **顯著上升 ($\uparrow\uparrow$)** | 陰性（未結合型不溶於水不過濾） | **顯著增加 ($\uparrow\uparrow$)** | 紅血球破壞過多，超過肝臟結合能力；糞便深褐色 |
| **吉伯特症候群 (Gilbert)** | 正常 | **輕度上升 ($\uparrow$)** | 陰性 | 正常 | **UGT1A1 葡萄糖醛酸轉移酶活性低下（約 30%）**；禁食、疲勞或感染時輕微黃疸，預後良性 |
| **克里格勒-納賈爾症候群 (Crigler-Najjar Type I)** | 檢測不到 | **極度危險性暴增 ($\uparrow\uparrow\uparrow$)** | 陰性 | 缺乏 | **UGT1A1 完全缺失**；新生兒期發生嚴重視神經與基底核核黃疸（Kernicterus）致死 |
| **杜賓-強森症候群 (Dubin-Johnson)** | **顯著上升 ($\uparrow\uparrow$)** | 正常或微升 | **強陽性** | 減少 | **MRP2 膽紅素向毛細膽管轉運蛋白缺陷**；肝臟外觀呈**深黑/黑褐色** |
| **阻塞性黃疸 (膽結石、胰頭癌)** | **顯著暴增 ($\uparrow\uparrow\uparrow$)** | 輕度增加 | **強陽性** | **陰性/缺乏** | 膽道完全阻塞，膽汁無法入腸；**糞便呈陶土白便（Clay-colored stools）**、皮膚奇癢 |
