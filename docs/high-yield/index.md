# 跨學科高頻考點整合導引（系統性思維鏈）

醫師國考第一階段（醫學一、醫學二）共 200 題單選題。傳統分科複習容易造成知識割裂，而考選部近年試題大量朝向「基礎結合臨床」、「跨學科連鎖題組」方向命題。

本專區建立 **八大器官系統整合思維鏈**，將分散在九大學科的考點沿著臨床生理與病理軸線徹底貫通：

$$\text{[解剖/胚胎發育]} \longrightarrow \text{[生理調節/生化代謝]} \longrightarrow \text{[病理形態/致病機轉]} \longrightarrow \text{[藥理靶點/臨床藥物]}$$

---

## 八大器官系統跨學科導引地圖

| 器官系統專題 | 跨科串聯學科 | 核心思維鏈概要 |
| :--- | :--- | :--- |
| [**1. 心血管系統整合**](cardiovascular.md) | 解剖 + 生理 + 病理 + 藥理 | 冠狀動脈支配 $\to$ 心室 PV Loop $\to$ 心肌梗塞演變 $\to$ 心衰竭四巨頭用藥 |
| [**2. 呼吸系統整合**](respiratory.md) | 解剖 + 組胚 + 生理 + 病理 + 藥理 | 氣道解剖與分葉 $\to$ 肺容量與 V/Q 比 $\to$ COPD/氣喘病理 $\to$ 支氣管擴張劑 |
| [**3. 腎臟與泌尿系統整合**](renal.md) | 解剖 + 胚胎 + 生理 + 病理 + 藥理 | 腎血管與輸尿管 $\to$ 逆流倍增與 RAAS $\to$ 腎絲球腎炎分類 $\to$ 五大類利尿劑 |
| [**4. 消化與肝膽胰系統整合**](gastrointestinal.md) | 解剖 + 胚胎 + 生理 + 生化 + 病理 | 腹腔動脈分支與門脈吻合 $\to$ 胃酸分泌機轉 $\to$ 肝硬化/黃疸病理 $\to$ 潰瘍用藥 |
| [**5. 神經科學與中樞系統整合**](neuroscience.md) | 神解 + 組胚 + 生理 + 藥理 + 病理 | 脊髓傳導束/腦神經 $\to$ 突觸傳導物 $\to$ 中風/神經退化疾患 $\to$ 抗精神/抗癲癇藥 |
| [**6. 內分泌與新陳代謝整合**](endocrine_metabolism.md) | 生理 + 生化 + 病理 + 藥理 | 下丘腦-垂體-靶腺軸 $\to$ 醣脂代謝路徑 $\to$ 糖尿病/甲狀腺病理 $\to$ 降血糖/類固醇 |
| [**7. 感染免疫與化學治療整合**](antimicrobial_infectious.md) | 微免 + 寄生蟲 + 藥理 + 病理 | 細菌/病毒/真菌結構 $\to$ 補體與細胞免疫 $\to$ 敗血休克 $\to$ 抗生素機轉與耐藥性 |
| [**8. 血液腫瘤與精準醫學整合**](oncology_hematology.md) | 組胚 + 生化 + 病理 + 藥理 | 骨髓造血與淋巴組織 $\to$ 凝血路徑/一碳循環 $\to$ 白血病/淋巴瘤 $\to$ 化療與標靶藥物 |

---

> [!TIP]
> 考前倒數階段建議優先精讀本專區八大思維鏈，搭配各科目具體章節深度查閱，可達最高複習投資報酬率。
