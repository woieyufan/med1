# 抗生素機轉與抗藥性跨學科大整合

## 抗生素作用靶點全景圖

```
[細胞壁合成抑制]
  - 阻斷轉肽作用 (PBP): Penicillins, Cephalosporins, Carbapenems, Monobactam
  - 結合 D-Ala-D-Ala: Vancomycin
  - 阻斷轉運: Bacitracin

[細胞膜通透性破壞]
  - Polymyxins (Colistin): 破壞革蘭氏陰性外膜 LPS
  - Daptomycin: 插入革蘭氏陽性菌膜形成離子孔洞

[蛋白質合成抑制 (Buy AT 30, CCEL at 50)]
  - 30S 亞基: Aminoglycosides (殺菌), Tetracyclines (抑菌)
  - 50S 亞基: Chloramphenicol, Clindamycin, Macrolides, Linezolid

[核酸代謝與合成抑制]
  - 葉酸合成途徑: Sulfonamides (抑制二氫葉酸合成酶), Trimethoprim (抑制二氫葉酸還原酶)
  - DNA 拓撲異構酶 / 旋轉酶: Fluoroquinolones (Ciprofloxacin, Levofloxacin)
  - RNA 聚合酶: Rifampin
```

## 重要耐藥菌株與抗藥機轉對照表

| 耐藥菌株類型 | 關鍵抗藥性分子機轉 | 克服方式與首選治療藥物 |
| :--- | :--- | :--- |
| **MRSA (耐甲氧西林金黃色葡萄球菌)** | 獲得 *mecA* 基因，產生變異青黴素結合蛋白 **PBP2a**（對所有 $\beta$-內醯胺類親和力極低） | **Vancomycin**, **Daptomycin**, **Linezolid**, Ceftaroline (第 5 代頭孢) |
| **VRE (耐萬古黴素腸球菌)** | 肽聚糖末端變更為 **D-Ala-D-Lac**（Vancomycin 無法結合） | **Linezolid**, **Daptomycin**, Tigecycline |
| **ESBL (超廣效 $\beta$-內醯胺酶)** | 質體介導突變型 $\beta$-內醯胺酶，水解青黴素、頭孢菌素、單環類 | **Carbapenems (Meropenem, Imipenem)** 首選 |
| **CRE (耐碳青黴烯腸道菌)** | 產生碳青黴烯酶（如 KPC, NDM-1 金屬酶） | Ceftazidime-avibactam, Colistin, Tigecycline |
| **綠膿桿菌 (P. aeruginosa)** | 多重外排泵 (Efflux pumps)、孔道蛋白 (Porin OprD) 缺失、AmpC $\beta$-內醯胺酶 | Piperacillin-tazobactam, Cefepime, Ceftazidime, Meropenem |
