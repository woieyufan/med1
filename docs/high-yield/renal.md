# 腎臟與泌尿系統跨學科高頻考點整合

腎臟系統結合了腎血管解剖、腎絲球過濾與逆流倍增生理學、各型腎絲球腎炎病理學，以及五大類利尿劑的作用機轉。

---

## 跨學科整合思維鏈

```
[解剖/組胚] 腎筋膜 (Gerota) ──► 輸尿管三個狹窄 ──► 後腎 (Metanephros) 與輸尿管芽交互誘導發育
   │
   ▼
[生理] 腎小球過濾率 (GFR 自我調節: 入球前列腺素擴張 + 出球血管張力素 II 收縮) ──► 逆流倍增系統
   │
   ▼
[病理] 免疫複合物沉積 ──► 腎炎綜合徵 (Nephritic: 血尿/高血壓) vs 腎病綜合徵 (Nephrotic: 巨量蛋白尿/水腫)
   │
   ▼
[藥理] 利尿劑五大家族 (CAI ──► Loop ──► Thiazide ──► K-sparing ──► Osmotic) ──► RAAS 阻斷劑
```

## 腎絲球腎炎病理學分類全覽（Nephritic vs Nephrotic）

| 症候群大類 | 疾病名稱 | 光學顯微鏡 (LM) | 免疫螢光 (IF) | 電子顯微鏡 (EM) | 國考關鍵特徵 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **腎病症候群 (Nephrotic)**<br>*(尿蛋白 $>3.5\text{ g/day}$, 低白蛋白, 嚴重水腫)* | **微小病變 (MCD)** | 腎絲球外觀正常 | 陰性（無沉積） | **足細胞足突廣泛融合抹平 (Effacement)** | 兒童最常見腎病症候群；類固醇治療極度敏感 |
| | **局部節段硬化 (FSGS)** | 部分腎絲球之部分毛細血管硬化 | 局部非特異性 IgM/C3 | 足突融合抹平 | 成人黑人、HIV 感染者高發；對類固醇反應差 |
| | **膜性腎病 (MN)** | 腎絲球毛細血管壁廣泛瀰漫性增厚 | 顆粒狀 IgG 與 C3 沿基底膜沉積 | **上皮下（Subepithelial）沉積，伴基底膜“釘突” (Spike and Dome)** | 成人白人高發；常與抗 PLA2R 抗體相關 |
| **腎炎症候群 (Nephritic)**<br>*(血尿、紅血球圓柱、寡尿、高血壓)* | **鏈球菌感染後 (PSGN)** | 腎絲球腫大、細胞增生性浸潤 | 星空狀（Starry sky）粗顆粒 IgG/C3 | **上皮下巨大“駝峰狀”沉積 (Subepithelial humps)** | 鏈球菌咽喉/皮膚感染後 1~3 週；補體 C3 下降 |
| | **IgA 腎病 (Berger病)** | 腎絲球繫膜區（Mesangium）增生 | **繫膜區顯著顆粒狀 IgA 沉積** | 繫膜區電子緻密物沉積 | 全球最常見原發性腎絲球腎炎；呼吸道感染後 1~2 天即發突發肉眼血尿 |
| | **急進性 (RPGN)** | **壁層上皮細胞增生形成“新月體” (Crescents)** | 依病因：Type I 線狀、Type II 顆粒、Type III 陰性 (Pauci-immune) | 基底膜斷裂穿孔 | 迅速進展為急性腎衰竭；Type III 多與 ANCA 相關血管炎有關 |

## 五大類利尿劑作用部位、離子排泄與臨床考點對照表

| 利尿劑分類 | 代表藥物 | 主要作用腎小管節段 | 作用分子靶點 | 尿液電解質變化 | 關鍵不良反應與臨床禁忌 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **碳酸酐酶抑制劑 (CAI)** | **Acetazolamide** | **近曲小管 (PCT)** | 抑制管腔面及胞內碳酸酐酶 (CA) | $\uparrow\ \text{Na}^+, \text{K}^+, \text{HCO}_3^-$ | 高氯性代謝性酸中毒、低血鉀；臨床用於**急性青光眼、高山症預防** |
| **環利尿劑 (Loop)** | **Furosemide, Bumetanide** | **亨利氏環粗上升支 (TAL)** | 阻斷 **$\text{Na}^+-\text{K}^+-2\text{Cl}^-$ 共同轉運蛋白** | $\uparrow\ \text{Na}^+, \text{K}^+, \text{Cl}^-, \text{Ca}^{2+}, \text{Mg}^{2+}$ | **低血鉀性鹼中毒、耳毒性 (Ototoxicity)**、低血鈣、高尿酸血症；急性肺水腫首選 |
| **遠曲小管利尿劑 (Thiazides)** | **Hydrochlorothiazide** | **遠曲小管初段 (DCT)** | 阻斷 **$\text{Na}^+-\text{Cl}^-$ 共同轉運蛋白** | $\uparrow\ \text{Na}^+, \text{K}^+, \text{Cl}^-$, **$\downarrow\ \text{Ca}^{2+}$ (保鈣!)** | 低血鉀性鹼中毒、**高血鈣、高尿酸、高血糖、高血脂**；高血壓合併骨質疏鬆首選 |
| **保鉀型利尿劑 (K-sparing)** | **Spironolactone, Amiloride** | **皮質集尿管 (CCT)** | 醛固酮受體拮抗 (Spir) 或阻斷 ENaC 鈉通道 (Amil) | $\uparrow\ \text{Na}^+$, **$\downarrow\ \text{K}^+, \downarrow\ \text{H}^+$ (保鉀保酸)** | **高血鉀症**；Spironolactone 具抗雄素副作用易致男性女乳症 |
| **滲透性利尿劑 (Osmotic)** | **Mannitol** | 全腎小管（主要是近曲小管及亨利氏環下降降支） | 增加管腔液滲透壓，抑制水被動重吸收 | $\uparrow$ 顯著排水 | 充血性心衰竭病患禁用（易誘發急性肺水腫）；用於**降低腦壓、眼內壓** |
