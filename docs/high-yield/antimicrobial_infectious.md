# 感染免疫與化學治療跨學科高頻考點整合

感染與免疫系統結合細菌病毒真菌結構、抗原呈遞與補體適應性免疫反應、感染性休克與肉芽腫病理，以及抗微生物藥物作用機轉與耐藥機制。

---

## 跨學科整合思維鏈

```
[微免/寄生蟲] 病原體結構 (肽聚糖, LPS 內毒素, 病毒套膜) ──► 補體 MAC 孔洞 ──► MHC 抗原呈遞
   │
   ▼
[免疫反應] TLR 模式識別受體 ──► 巨噬細胞釋放 TNF-α, IL-1, IL-6 ──► 樹突細胞活化 CD4+/CD8+ T 細胞
   │
   ▼
[病理] 血管通透性暴增 ──► 敗血性休克 (Septic shock)；巨噬細胞上皮樣轉變 ──► 乾酪性肉芽腫
   │
   ▼
[藥理] 殺菌/抑菌靶點 (細胞壁 β-lactams/Vancomycin ──► 核糖體 30S/50S ──► 拓撲異構酶 Quinolones)
```

## 抗生素分子作用靶點、抗菌譜與關鍵口訣

```
【核糖體蛋白質合成抑制劑經典口訣】
  Buy AT 30, CCEL (Sell) at 50!
  - 30S 亞基抑制劑：Aminoglycosides (殺菌劑 bactericidal), Tetracyclines (抑菌劑 bacteriostatic)
  - 50S 亞基抑制劑：Chloramphenicol, Clindamycin, Erythromycin (Macrolides), Linezolid
```

| 抗生素大類 | 代表藥物 | 核心分子靶點與殺菌機轉 | 臨床首選適應症 | 關鍵不良反應與耐藥機轉 |
| :--- | :--- | :--- | :--- | :--- |
| **青黴素類與頭孢菌素** | **Ampicillin, Ceftriaxone, Cefepime** | 結構類似 D-Ala-D-Ala，共價結合抑制轉肽酶（Penicillin-Binding Proteins, PBPs），破壞細胞壁 | 廣效抗菌；Ceftriaxone 腦膜炎首選；Cefepime 抗綠膿桿菌 | 過敏反應；耐藥主因：產生 $\beta$-內醯胺酶或變異 **PBP2a (MRSA)** |
| **碳青黴烯類 (Carbapenems)** | **Meropenem, Imipenem** | 超廣效結合 PBPs，耐絕大多數 $\beta$-內醯胺酶 | **產 ESBL 腸道菌嚴重感染首選** | 降低癲癇閾值（Imipenem 最甚）；耐藥株產生碳青黴烯酶（KPC, NDM-1） |
| **糖肽類 (Glycopeptides)** | **Vancomycin** | 直接結合細胞壁肽聚糖前體之 **D-Ala-D-Ala 末端**，立體阻斷轉肽與轉糖基化 | **MRSA、困難梭狀桿菌結腸炎（口服）** | **紅人症候群 (Red man syndrome)**（組胺釋放，需減慢滴速）、耳毒性、腎毒性；VRE 耐藥突變為 D-Ala-D-Lac |
| **氨基糖苷類 (Aminoglycosides)** | **Gentamicin, Amikacin** | 不可逆結合 **30S 核糖體**，誤讀遺傳密碼並破壞膜完整性（少數殺菌型蛋白質抑制劑） | 革蘭氏陰性嚴重菌血症、心內膜炎協同治療 | **顯著腎毒性 (ATN)、不可逆耳毒性、神經肌肉阻滯**；需氧菌攝取依賴氧氣 |
| **四環黴素類 (Tetracyclines)** | **Doxycycline** | 可逆結合 **30S 核糖體**，阻斷 aminoacyl-tRNA 進入 A 位點 | 非典型肺炎（黴漿菌、披衣菌）、立克次體斑疹傷寒、萊姆病 | **沉積於牙齒與骨骼導致骨骼發育遲緩及牙齒永久變色**；孕婦及 8 歲以下兒童禁用 |
| **巨環類 (Macrolides)** | **Azithromycin, Clarithromycin** | 結合 **50S 核糖體 23S rRNA**，阻斷肽鏈延伸與移位作用 | 社區型肺炎、百日咳、披衣菌披衣性尿道炎 | **心臟 QT 間期延長誘發 TdP 致命心律不整**；急性膽汁淤積性肝炎；CYP3A4 抑制 |
| **氟喹諾酮類 (Fluoroquinolones)** | **Ciprofloxacin, Levofloxacin** | 抑制細菌 **DNA 拓撲異構酶 II (DNA gyrase) 及拓撲異構酶 IV**，引發雙股 DNA 斷裂 | 複雜性泌尿道感染、肺囊蟲、炭疽熱 | **肌腱炎與肌腱斷裂（阿基里斯腱斷裂 Achilles tendon rupture）**、QT 延長、影響軟骨生長（孕婦幼童避用） |
