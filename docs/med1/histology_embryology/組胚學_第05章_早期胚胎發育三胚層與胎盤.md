# 組織與胚胎學 第 05 章：早期胚胎發育、三胚層與胎盤
> **考綱歸屬**：組織學與胚胎學 ｜ 醫師專技高考一階段高頻必考核心

### 科目：人體胚胎學 ｜ 醫學（一）Q31~Q43 必考核心

---

## 本章導讀與知識架構定位

早期人體胚胎發育是生命藍圖展開的最關鍵時期。考選部在此處出題精準鎖定胚胎發育的時間節點與細胞命運圖譜：從第一週受精卵裂至囊胚期突破透明層孵化（Hatching）、第二週二胚層胚盤形成、第三週原條誘導原腸胚形成（Gastrulation），到三大胚層（外胚層、中胚層、內胚層）的終極分化命運矩陣。其中**「神經脊細胞（Neural Crest Cells）衍生物全覽」**更是每年國考必出 1 至 2 題的超級重分題。

本章下轄三大核心主題：
1. **主題 5.1：受精卵裂、囊胚形成、突破透明層與二胚層期**（受精部位、桑椹胚、囊胚內細胞群與滋養層、孵化機制、植入部位與前置胎盤、第二週二胚層上胚層與下胚層、合體滋養層分泌 hCG）
2. **主題 5.2：原腸胚形成、三胚層分化命運與神經脊細胞**（原條原結形成、三胚層發生、外中內胚層命運全表、神經脊細胞四大遷移路徑與衍生物全覽矩陣）
3. **主題 5.3：胎盤構造、絨毛演化、臍帶與雙胞胎類型**（一級/二級/三級絨毛微細血管、底蛻膜胎盤母體面、臍帶一靜兩動、單卵雙胎卵裂時間與絨毛膜羊膜腔配置關係）

# 主題 5.1：受精卵裂、囊胚形成、突破透明層與二胚層期

### 重點一：核心高頻速查矩陣

#### 1. 胚胎發育第一週至第二週發育時間線（國考時間點矩陣）
| 發育時間 | 胚胎形態發育階段 | 關鍵生化事件與解剖位置 | 臨床考點與病理關聯 |
| :--- | :--- | :--- | :--- |
| **Day 0 (0 天)** | **受精卵 (Zygote)** | 發生於輸卵管**「壺腹部 (Ampulla)」**；精卵質膜融合激發皮質顆粒釋放（多精受精阻斷） | 雙倍體染色體核型（46, XX 或 46, XY）建立 |
| **Day 1 ~ 3** | **卵裂與桑椹胚 (Morula)** | 受精卵進行有絲分裂（細胞變小）；Day 3 形成約 16 個細胞實心球，被透明層（Zona pellucida）包裹 | 胚胎沿輸卵管向子宮腔推進 |
| **Day 4 ~ 5** | **囊胚 (Blastocyst)** | 細胞分化為兩大群：<br>1. **滋養層 (Trophoblast)**（外層，發育為胎盤）<br>2. **內細胞群 (Inner cell mass / ICM)**（內層，發育為胚胎本身） | 囊胚腔（Blastocyst cavity）積水膨大 |
| **Day 5 ~ 6** | **突破透明層孵化**<br>**(Hatching)** | 囊胚分泌水解酶，**「溶解並完全突破脫離透明層（Zona pellucida）」**！ | **囊胚必須成功突破脫去透明層，才能使滋養層直接接觸子宮內膜並完成植入（Implantation）！** |
| **Day 6 ~ 7** | **植入起始 (Implantation)** | 囊胚滋養層黏附於**子宮後壁或前壁上部**子宮內膜上皮；滋養層接觸內膜後分化為**細胞滋養層**與多核的**合體滋養層** | 若植入子宮下段近子宮頸內口，引發**前置胎盤 (Placenta previa)** 大出血；異位妊娠最常在輸卵管壺腹部 |
| **第二週 (Day 8~14)**<br>*(成雙之週！)* | **二胚層原胚盤 (Bilaminar disc)** | 1. 內細胞群分化為兩層：**上胚層 (Epiblast)** 與 **下胚層 (Hypoblast)**<br>2. 形成兩個腔體：**羊膜腔**（上胚層背側）與 **原發卵黃囊**（下胚層腹側）<br>3. 滋養層分化為：**細胞滋養層**與**合體滋養層** | **合體滋養層分泌人絨毛膜促性腺激素 (hCG)**（維持黃體分泌孕酮；受精後第 8~10 天血清或尿液即可驗孕陽性！） |

# 主題 5.2：原腸胚形成、三胚層分化命運與神經脊細胞

### 重點一：核心高頻速查矩陣

#### 1. 第三週原腸胚形成（Gastrulation）
- 胚胎發育第 15 天，上胚層後部正中線形成一條淺溝——**原條（Primitive streak）**，前端膨大為**原結（Primitive node）**與原坑。
- **上胚層細胞進行內陷（Invagination）移動**：
  - 第一波細胞置換下胚層，形成**「內胚層（Endoderm）」**。
  - 第二波細胞滯留在上胚層與內胚層之間，形成**「中胚層（Mesoderm）」**。
  - 留在表面的上胚層細胞轉化為**「外胚層（Ectoderm）」**。
- **上胚層（Epiblast）是人體所有三大胚層的唯一共同細胞來源！**

#### 2. 三大胚層組織分化命運終極速查矩陣（必考表格）
| 原始胚層名稱 | 次級分化結構 | 人體最終發育衍生的器官與組織（必考對照！） |
| :--- | :--- | :--- |
| **外胚層**<br>**(Ectoderm)** | **表面外胚層** | **皮膚表皮及其附屬器（毛髮、指甲、汗腺、皮脂腺、乳腺）**、口腔黏膜上皮、**眼晶狀體 (Lens)**、內耳迷路、牙齒造釉質（琺瑯質）、**腦下垂體前葉 (腺垂體)**、肛門下段上皮 |
| | **神經神經管** | **整個中樞神經系統 (CNS: 大腦、小腦、腦幹、脊髓)**、神經垂體（後葉）、松果體、**視網膜** |
| | **神經脊 (Neural Crest)** | *(見下方專題表格，超高頻！)* |
| **中胚層**<br>**(Mesoderm)** | **軸旁中胚層 (Paraxial)** | **體節 (Somites)** $\to$ 生骨節（脊椎骨、肋骨）、生肌節（骨骼肌）、生皮節（**真皮**） |
| | **間介中胚層 (Intermediate)** | **泌尿生殖系統全部（腎臟、輸尿管、睪丸、卵巢、生殖管道）**；*(除外陰與膀胱上皮)* |
| | **側板中胚層 (Lateral plate)** | **心血管系統（心臟、全身血管、血液細胞）**、體腔被膜（胸膜、腹膜、心包膜）、**骨盆四肢骨骼** |
| | 其他特化結構 | **腎上腺皮質 (Adrenal cortex)**、脾臟、小膠質細胞 |
| **內胚層**<br>**(Endoderm)** | **原始腸管 (Gut tube)** | **消化道上皮**（自咽部至直腸上段齒狀線）、**消化腺體實質（肝臟、膽囊上皮、胰臟）**、**呼吸道上皮（喉、氣管、支氣管、肺泡上皮）**、**甲狀腺濾泡細胞**、副甲狀腺主細胞、胸腺上皮、膀胱與大部分尿道上皮、中耳鼓室與咽鼓管黏膜 |

#### 3. 神經脊細胞（Neural Crest Cells）衍生物全覽（國考出題率最高考點！）
神經管閉合時脫落並廣泛遷徙至全身的外胚層細胞群（稱第四胚層）：
$$\begin{array}{l}
\mathbf{神經脊核心衍生物清單 (必背！)}： \\
\text{1. \textbf{所有周邊神經系統節細胞}：脊神經背根神經節 (DRG)、自主神經節 (交感神經節、副交感神經節)、腦神經感覺神經節} \\
\text{2. \textbf{周邊神經膠質細胞}：許旺細胞 (Schwann cells)、神經節衛星細胞} \\
\text{3. \textbf{腎上腺髓質嗜鉻細胞} (Chromaffin cells，分泌兒茶酚胺)} \\
\text{4. \textbf{黑色素細胞} (Melanocytes，遷移至皮膚真皮與表皮基底層)} \\
\text{5. \textbf{心臟大動脈主動脈肺動脈螺旋中隔} (Aorticopulmonary septum，缺乏致法洛氏四重症或大動脈轉位)} \\
\text{6. \textbf{頭頸部鰓弓骨骼軟骨與結締組織} (面顱骨、下頜骨、聽小骨鎚骨砧骨、牙齒牙本質與牙骨質)} \\
\text{7. \textbf{甲狀腺濾泡旁 C 細胞} (Parafollicular C cells，分泌降鈣素)} \\
\text{8. \textbf{腦膜軟腦膜與蛛網膜} (Leptomeninges，唯硬腦膜來自中胚層！)} \\
\text{9. \textbf{角膜基質與角膜內皮}}
\end{array}$$

# 主題 5.3：胎盤構造、絨毛演化、臍帶與雙胞胎類型

### 重點一：核心高頻速查矩陣

#### 1. 絨毛膜絨毛（Chorionic Villi）三級演進結構
| 絨毛階段 | 發育時間 | 絨毛內部包含的微細組織學層次（國考必考） | 核心功能特徵 |
| :--- | :--- | :--- | :--- |
| **初級絨毛 (Primary)** | 第二週末 (Day 11~13) | **合體滋養層 (外) + 細胞滋養層柱 (內)**；無間質 | 剛形成指狀突起 |
| **次級絨毛 (Secondary)** | 第三週初 (Day 16) | **合體滋養層 + 細胞滋養層 + 胚外中胚層結締組織核心** | 胚外中胚層長入初級絨毛中心，但**「尚無血管」** |
| **三級絨毛 (Tertiary)**<br>*(終末幹絨毛)* | **第三週末 (Day 21)** | **合體滋養層 + 細胞滋養層 + 結締組織中長出「胎兒毛細血管網與原始血球」！** | **胎盤胎兒側微血管循環完全建立**，與臍帶血管相連開始進行母胎氣體物質交換！ |

#### 2. 單卵雙胞胎（Monozygotic Twins）分裂時間與胎膜配置關係
| 胚胎分裂發生時間點 | 絨毛膜（Chorion）狀態 | 羊膜囊（Amniotic sac）狀態 | 胎盤配置與臨床併發症 |
| :--- | :--- | :--- | :--- |
| **0 ~ 3 天** (卵裂桑椹胚期) | **雙絨毛膜 (Dichorionic)** | **雙羊膜囊 (Diamniotic)** | 2 個獨立胎盤（或融合胎盤）；與雙卵雙胞胎完全相同，併發症最低 |
| **4 ~ 8 天** (囊胚期，**最常見！佔 75%**) | **單絨毛膜 (Monochorionic)** | **雙羊膜囊 (Diamniotic)** | **1 個共同胎盤，2 個獨立羊膜腔**（中間隔有一層雙層羊膜薄膜）；易發生**雙胞胎輸血症候群 (TTTS)**！ |
| **8 ~ 12 天** (植入後二胚層期) | **單絨毛膜 (Monochorionic)** | **單羊膜囊 (Monoamniotic)** | **1 個共同胎盤，1 個共同羊膜腔！** 極度危險，**兩條臍帶極易相互纏繞打結致胎死腹中**（死亡率高達 50%）！ |
| **> 13 天** (原條形成後分裂) | 單絨毛膜 | 單羊膜囊 | 分裂不完全引發**「連體嬰 (Conjoined twins)」** |

## 考選部歷屆魔鬼陷阱與抽換標靶

!!! warning "高頻陷阱重點防護（考試最易混淆點）"

    - **【突破透明層（Hatching）時間階段】**：
        - 胚胎是在**「囊胚期（Blastocyst）」**溶解並突破透明層！
        - 絕不是桑椹胚期或原腸胚期。突破透明層後才能完成子宮內膜植入。

    - **【腎上腺兩大部位胚層完全不同】**：
        - **腎上腺皮質**：源自**「中胚層（Mesoderm）」**。
        - **腎上腺髓質**：源自**「外胚層神經脊（Neural crest）」**！

    - **【三級絨毛獨有構造】**：
        - 三級絨毛（Tertiary villus）與二級絨毛唯一的鑑別關鍵是：**內部是否長出「胎兒毛細血管與血球」**！

## 歷屆國考經典真題實戰解析

#### 【115 年 第一次 醫學（一） 第 33 題】
**胚胎發育至何種時期，會突破透明層（zona pellucida）並準備進行著床？**
- (A) 桑椹胚（morula）
- (B) 二胚層原胚盤（bilaminar embryonic disc）
- (C) 三胚層原胚盤（trilaminar embryonic disc）
- (D) 囊胚（blastocyst）

**【正解】(D)**
**【逐項剖析】**
- **早期胚胎發育與植入時序剖析**：
  - 受精卵在輸卵管內連續分裂，在第 3 天形成約 16 個細胞的桑椹胚，此時外面始終緊密包裹著堅韌的透明層（Zona pellucida），以防止胚胎過早黏附在輸卵管壁造成子宮外孕。
  - 當胚胎在第 4~5 天進入子宮腔後，液體滲入形成囊胚腔，此發育階段稱為**「囊胚（Blastocyst）」**。
  - 在第 5~6 天即將植入前，囊胚滋養層細胞分泌蛋白水解酶，在透明層上消化溶出一個孔隙，囊胚由此孔道擠壓脫殼而出，此關鍵生化過程稱為**「突破透明層（Hatching / 孵化）」**。只有脫去透明層的囊胚，其滋養層細胞才能直接接觸子宮內膜上皮進行著床植入。故選 **(D)**。

#### 【115 年 第一次 醫學（一） 第 35 題】
**下列何種構造之來源不是外胚層（ectoderm）？**
- (A) 視網膜（retina）
- (B) 黑色素細胞（melanocytes）
- (C) 腦下垂體前葉（anterior pituitary）
- (D) 腎上腺皮質（adrenal cortex）

**【正解】(D)**
**【逐項剖析】**
- **胚層分化來源對照**：
  - **(A) 視網膜**：源自神經外胚層間腦兩側突出的視泡與視杯（Neuroectoderm）。
  - **(B) 黑色素細胞**：源自外胚層神經脊（Neural crest cells）。
  - **(C) 腦下垂體前葉（腺垂體）**：源自原始口腔頂部的表面外胚層（Surface ectoderm）向上突起形成的 Rathke 氏囊。
  - **(D) 正選**：**腎上腺皮質（Adrenal cortex）源自「體腔上皮中胚層（Mesoderm）」**！唯有其內部的腎上腺髓質才源自外胚層神經脊。故不是外胚層來源者為 (D)。

---

#### 【110 年 第二次 醫學（一） 第 32 題】
**下列何者只出現於絨毛膜的三級絨毛（tertiary chorionic villus）內？**
- (A) 合體滋養層細胞（syncytiotrophoblast）
- (B) 細胞滋養層細胞（cytotrophoblast）
- (C) 胚外中胚層（extraembryonic mesoderm）
- (D) 微血管（capillaries）

**【正解】(D)**
**【逐項剖析】**
- **絨毛膜絨毛發育三階段剖析**：
  - 初級絨毛：僅由合體滋養層及其內部的細胞滋養層細胞團構成。
  - 次級絨毛：胚外中胚層間質長入初級絨毛軸心。
  - **三級絨毛（Tertiary chorionic villi）**：在發育第三週末，絨毛軸心內的胚外中胚層間質細胞分化為**「微血管（Capillaries）與原始血球」**，並與胚胎內部的臍血管建立連通，正式開啟胎盤微循環。因此微血管是三級絨毛獨一無二的特化標誌，故選 **(D)**。

---

#### 【111 年 第一次 醫學（一） 第 32 題】
**下列何者由軸旁中胚層（paraxial mesoderm）衍生而來？**
- (A) 腎臟（kidney）
- (B) 骨骼肌（skeletal muscle）
- (C) 心臟（heart）
- (D) 睪丸（testis）

**【正解】(B)**
**【逐項剖析】**
- **中胚層三大部分分化命運剖析**：
  - **軸旁中胚層（Paraxial mesoderm）**：沿神經管與脊索兩側分節形成 42~44 對**體節（Somites）**，體節進一步分化為生骨節（中軸骨骼）、生皮節（背部真皮）及**「生肌節（Myotome，分化為全身骨骼肌）」**，故 **(B) 正確**！
  - **間介中胚層（Intermediate mesoderm）**：分化為泌尿生殖系統，即 **(A) 腎臟** 與 **(D) 睪丸**。
  - **側板中胚層（Lateral plate mesoderm）**：臟壁層分化為 **(C) 心臟** 與循環血管系統。
