# 神經解剖學高頻考點

## 脊髓主要傳導路徑（Spinal Tracts）

| 傳導路徑 | 傳導感覺 / 功能 | 一級神經元 / 交叉位置 | 脊髓半切症候群表現（Brown-Séquard） |
| :--- | :--- | :--- | :--- |
| **背柱內側丘系 (DCML)** | 意識本體感覺、兩點辨別覺、震動覺 | 延腦薄束核 / 楔狀核交叉（內弓狀纖維） | **同側**病灶節段以下本體感覺與震動覺喪失 |
| **外側脊髓丘腦徑 (Spinothalamic)** | 痛覺、溫覺 | 入脊髓後 1~2 節段於前聯合白質交叉 | **對側**病灶節段 1~2 節以下痛溫覺喪失 |
| **外側皮質脊髓徑 (Corticospinal)** | 隨意運動控制 | 延腦錐體交叉（約 85% 纖維） | **同側**病灶節段以下痙攣性癱瘓（上運動神經元徵象） |

## 腦幹截面定位症候群（Brainstem Syndromes）

!!! note "Wallenberg Syndrome (延腦背外側症候群)"
    - **受損血管**：後下小腦動脈（PICA, Posterior Inferior Cerebellar Artery）或脊椎動脈。
    - **三叉神經脊髓核受損**：同側臉部痛溫覺喪失。
    - **脊髓丘腦徑受損**：對側軀幹與肢體痛溫覺喪失（交叉型痛溫覺喪失）。
    - **疑核 (Nucleus ambiguus, CN IX, X) 受損**：聲音嘶啞（吞嚥困難、作嘔反射消失、懸雍垂偏向健側）。
    - **前庭核受損**：眩暈、眼球震顫（Nystagmus）。
    - **下行交感神經纖維受損**：同側霍納氏症候群（Horner syndrome: 瞳孔縮小、眼瞼下垂、無汗）。

!!! warning "Weber Syndrome (中腦腹側症候群)"
    - **受損血管**：後大腦動脈（PCA）分枝。
    - **動眼神經根受損**：同側動眼神經麻痺（上瞼下垂、瞳孔散大、外下斜視）。
    - **大腦腳底皮質脊髓徑受損**：對側肢體痙攣性偏癱。
