# 組織學高頻考點

## 上皮細胞分類與經典分佈

| 上皮組織型態 | 經典分佈器官 | 國考關鍵題型 |
| :--- | :--- | :--- |
| **單層扁平上皮** | 血管內皮、微血管、肺泡（Type I 肺泡細胞）、鮑氏囊壁層 | 物質擴散與滲透功能 |
| **單層立方上皮** | 腎近曲/遠曲小管、甲狀腺濾泡上皮、卵巢表面 | 分泌與吸收 |
| **單層柱狀上皮** | 胃黏膜、小腸黏膜（具微絨毛）、大腸、膽囊 | 具微絨毛與杯狀細胞 |
| **偽複層纖毛柱狀上皮** | 呼吸道（氣管、支氣管）、副睪（具立體纖毛 Stereocilia） | 纖毛運動清除黏液 |
| **複層扁平非角質化上皮** | 食道、口腔、陰道、子宮頸外口 | 耐機械摩擦磨損 |
| **移行上皮 (Urothelium)** | 腎盂、輸尿管、膀胱 | 具傘細胞（Umbrella cells），隨體積脹縮改變層數 |

## 淋巴器官微細構造

- **胸腺 (Thymus)**：皮質進行 T 細胞陽性選汰（TCR 辨識 MHC），髓質具 Hassall 氏小體（退化網狀上皮細胞）並進行陰性選汰。無淋巴濾泡、無傳入淋巴管。
- **脾臟 (Spleen)**：白髓包含中央動脈周圍淋巴鞘（PALS，主要是 T 細胞）與淋巴濾泡（主要是 B 細胞）；紅髓為脾索與血竇，負責過濾老化紅血球。
- **淋巴結 (Lymph node)**：外皮質有生發中心（B 細胞），旁皮質區具高內皮微靜脈（HEV，主要是 T 細胞），髓質含漿細胞與巨噬細胞。
