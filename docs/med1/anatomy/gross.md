# 大體解剖學高頻考點

## 腦神經出顱孔洞與走向（High-Yield Cranial Foramina）

!!! tip "國考必考核心 (Tier 1)"
    出顱孔洞與伴隨血管是每年必考 1~2 題的固定出題點。

| 顱孔孔洞（Foramen） | 通行構造（Nerve & Vessel） | 臨床與受損症狀 |
| :--- | :--- | :--- |
| **篩孔 (Cribriform plate)** | 嗅神經（CN I） | 嗅覺喪失（Anosmia） |
| **視神經管 (Optic canal)** | 視神經（CN II）、眼動脈（Ophthalmic a.） | 視力受損、瞳孔對光反射傳入異常 |
| **眶上裂 (Superior orbital fissure)** | CN III, IV, $V_1$, VI, 眼上靜脈 | 海綿竇症候群（痛性眼肌麻痺、額頭感覺喪失） |
| **圓孔 (Foramen rotundum)** | 三叉神經第二支（$V_2$, 上頜神經） | 中臉部感覺異常 |
| **卵圓孔 (Foramen ovale)** | 三叉神經第三支（$V_3$, 下頜神經）、副腦膜動脈 | 咀嚼肌無力、下臉部感覺喪失 |
| **棘孔 (Foramen spinosum)** | 中腦膜動脈（Middle meningeal a.） | 硬腦膜外血腫（Epidural hematoma, EDH） |
| **內耳道 (Internal acoustic meatus)** | CN VII（顏面神經）、CN VIII（前庭耳蝸神經）、內聽動脈 | 聽力喪失、周邊型顏面麻痺 |
| **頸靜脈孔 (Jugular foramen)** | CN IX, X, XI, 內頸靜脈 | 吞嚥困難、懸雍垂偏斜、斜方肌/胸鎖乳突肌無力 |
| **舌下神經管 (Hypoglossal canal)** | CN XII（舌下神經） | 伸舌偏向患側（患側萎縮） |

## 腹壁與腹股溝構造（Inguinal Canal）

### 直接型 vs 間接型腹股溝疝氣

```
腹壁下動脈 (Inferior epigastric vessels)
       │
  內側 │ 外側
 (直接型疝氣) │ (間接型疝氣)
Hesselbach三角 │ 經深環 (Deep ring)
直出腹直肌旁 │ 沿精索入陰囊
老人腹壁薄弱 │ 年輕人鞘突未閉合
```

| 項目 | 間接型腹股溝疝氣（Indirect） | 直接型腹股溝疝氣（Direct） |
| :--- | :--- | :--- |
| **好發族群** | 嬰幼兒、年輕男性 | 中老年男性 |
| **解剖位置** | 腹壁下動脈**外側** | 腹壁下動脈**內側**（海氏三角） |
| **疝氣通道** | 經深環、穿過腹股溝管、常進入陰囊 | 經腹壁筋膜缺陷直突表面、罕入陰囊 |
| **致病機轉** | 腹膜鞘狀突（Processus vaginalis）未閉合 | 腹壁肌肉萎縮（腹橫肌/腹內斜肌筋膜薄弱） |
