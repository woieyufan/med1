# 胚胎學高頻考點

## 咽囊（Pharyngeal Pouches）衍生物對照表

!!! tip "每年必考 1 題 (Tier 1)"
    記住「一耳、二桃、三下甲與胸、四上甲與降鈣素」。

| 咽囊編號 | 衍生構造 | 相關臨床異常 / 症候群 |
| :--- | :--- | :--- |
| **第 1 咽囊** | 中耳腔、耳咽管（歐氏管）、鼓膜內層表面 | 中耳感染與耳咽管閉鎖 |
| **第 2 咽囊** | 腭扁桃體上皮及其隱窩（Palatine tonsil） | 扁桃體窩發育 |
| **第 3 咽囊** | **下副甲狀腺**（背側）、**胸腺**（腹側） | **DiGeorge 症候群**（22q11 缺失，第 3、4 咽囊發育不全，導致低血鈣與 T 細胞缺陷） |
| **第 4 咽囊** | **上副甲狀腺**（背側）、濾泡旁 C 細胞（Ultimobranchial body，分泌降鈣素） | 副甲狀腺機能低下 |

## 主動脈弓（Aortic Arches）衍生物

- **第 1 弓**：上頜動脈（Maxillary artery）。
- **第 2 弓**：鐙骨動脈（Stapedial artery）與舌骨動脈。
- **第 3 弓**：總頸動脈（Common carotid）與內頸動脈近端。
- **第 4 弓**：左側形成**主動脈弓**（Aortic arch），右側形成右鎖骨下動脈近端。
- **第 6 弓**：近端形成肺動脈，左側遠端形成**動脈導管（Ductus arteriosus）**（退化為動脈韌帶）。
