# 病毒學高頻考點

## DNA 病毒分類大表

!!! tip "DNA 病毒通用口訣"
    除了 **Parvovirus**（單股 ssDNA）之外，其餘 DNA 病毒皆為**雙股 (dsDNA)**；除了 **Poxvirus**（複雜對稱，在細胞質複製）之外，其餘皆在**細胞核複製**。

| 病毒家族 | 基因型態 / 外膜 | 代表病毒 | 臨床重要考點 |
| :--- | :--- | :--- | :--- |
| **Parvoviridae** | ssDNA / **無外膜 (Naked)** | B19 病毒 | 傳染性紅斑（第五病，蘋果臉）、鐮刀型貧血病患再生不良危象、孕婦感染胎兒水腫 |
| **Papillomaviridae** | 環狀 dsDNA / **無外膜** | HPV (人乳頭瘤病毒) | HPV 6, 11 (尖形濕疣)；HPV 16, 18 (子宮頸癌，E6 抑 p53，E7 抑 Rb) |
| **Adenoviridae** | 線狀 dsDNA / **無外膜** | 腺病毒 | 咽結膜熱、出血性膀胱炎、嬰幼兒腹瀉 |
| **Hepadnaviridae** | 部分雙股環狀 / **有外膜** | B 型肝炎病毒 (HBV) | 具反轉錄酶活性（RNA intermediate）、Dane 顆粒 |
| **Herpesviridae** | 線狀 dsDNA / **有外膜** | HSV-1, HSV-2, VZV, EBV, CMV, HHV-6, HHV-8 | 潛伏感染能力（HSV 於三叉神經節，VZV 於背根神經節） |
| **Poxviridae** | 線狀 dsDNA / **有外膜** | 天花病毒、傳染性軟疣 | 體積最大，**唯一在宿主細胞質內複製與轉錄的 DNA 病毒** |
