# 細菌學高頻考點

## 革蘭氏陽性菌 vs 陰性菌構造對比

| 結構特徵 | 革蘭氏陽性菌 (Gram-positive) | 革蘭氏陰性菌 (Gram-negative) |
| :--- | :--- | :--- |
| **肽聚糖層 (Peptidoglycan)** | 濃厚多層（厚度 20~80 nm） | 薄單層（厚度 1~3 nm） |
| **外膜 (Outer membrane)** | 無 | **有**（含內毒素 LPS / 內毒素脂質 A） |
| **磷壁酸 (Teichoic acid)** | **有**（誘發發炎反應） | 無 |
| **周質空間 (Periplasmic space)** | 極窄或無 | 寬廣（含 $\beta$-內醯胺酶等分解酵素） |

## 重要細菌外毒素作用機轉總覽

| 細菌名稱 | 外毒素名稱 | 分子作用機轉 | 臨床特徵 |
| :--- | :--- | :--- | :--- |
| **白喉棒狀桿菌 (C. diphtheriae)** | 白喉毒素 (Diphtheria toxin) | **ADP-核糖基化延長因子-2 (EF-2)** | 咽喉灰色偽膜、心肌炎、神經炎 |
| **綠膿桿菌 (P. aeruginosa)** | 外毒素 A (Exotoxin A) | **ADP-核糖基化 EF-2**（機轉同白喉） | 燒燙傷感染、呼吸器相關肺炎 |
| **霍亂弧菌 (V. cholerae)** | 霍亂毒素 (Cholera toxin) | **持續活化 $G_s$ 蛋白 $\rightarrow$ cAMP 狂飆** | 米湯樣水瀉（Rice-water stool） |
| **百日咳桿菌 (B. pertussis)** | 百日咳毒素 (Pertussis toxin) | **抑制 $G_i$ 蛋白 $\rightarrow$ cAMP 上升** | 淋巴球顯著增多、陣發性劇烈咳嗽 |
| **破傷風桿菌 (C. tetani)** | 破傷風痙攣毒素 (Tetanospasmin) | 切斷 SNARE 蛋白，阻斷 **GABA / Glycine** 釋放 | 痙攣性癱瘓、牙關緊閉、角弓反張 |
| **肉毒桿菌 (C. botulinum)** | 肉毒毒素 (Botulinum toxin) | 切斷 SNARE 蛋白，阻斷神經肌肉接頭 **Ach** 釋放 | 弛緩性癱瘓（由頭至腳對稱性下行麻痺） |
