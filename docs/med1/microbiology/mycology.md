# 真菌學高頻考點

## 雙型性真菌（Dimorphic Fungi）

雙型性真菌的生長特性：**環境中呈黴菌型態（Cold, 25°C = Mold），宿主體內呈酵母菌型態（Heat, 37°C = Yeast）**。

| 真菌名稱 | 地理分佈 / 暴露來源 | 組織切片鏡檢特徵 | 臨床特色 |
| :--- | :--- | :--- | :--- |
| **組織胞漿菌 (Histoplasma capsulatum)** | 美國密西西比/俄亥俄河谷、鳥糞與蝙蝠糞（洞穴探險） | 巨噬細胞內充滿微小圓形酵母菌 | 模擬肺結核（肺部鈣化肉芽腫）、肝脾腫大 |
| **芽生菌 (Blastomyces dermatitidis)** | 美國東部與中西部大湖區、土壤腐木 | **寬基底出芽 (Broad-based budding)** | 肺部肉芽腫、皮膚潰瘍與骨骼侵犯 |
| **球黴菌 (Coccidioides immitis)** | 美國西南部沙漠地區（加州聖華金谷）、沙塵暴 | 巨大厚壁球囊（Spherules），內部充滿內生孢子 | 谷熱（Valley fever）、結節性紅斑、腦膜炎 |
| **副球黴菌 (Paracoccidioides brasiliensis)** | 拉丁美洲 | 船長舵形（Captain's wheel）多重出芽酵母菌 | 黏膜皮膚潰瘍、淋巴結腫大 |
