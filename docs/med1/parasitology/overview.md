# 寄生蟲學高頻考點

## 醫學寄生蟲感染型與宿主速讀表

寄生蟲每年必考 4~5 題，只要熟記傳播途徑與感染型態（Infective form）即可拿滿分數。

| 寄生蟲名稱 | 感染途徑與感染型態 | 中間宿主 / 媒介 | 臨床特徵與首選治療 |
| :--- | :--- | :--- | :--- |
| **中華肝吸蟲 (Clonorchis sinensis)** | 生食淡水魚蝦（囊蚴 Metacercaria） | 第 1：淡水螺；第 2：淡水魚 | 膽管炎、色素結石、**膽管癌 (Cholangiocarcinoma)**。首選 Praziquantel。 |
| **衛氏肺吸蟲 (Paragonimus westermani)** | 生食淡水蟹/螯蝦（囊蚴） | 第 1：螺；第 2：甲殼類（蟹） | 咳鐵鏽色痰（易誤診為肺結核）。首選 Praziquantel。 |
| **日本血吸蟲 (Schistosoma japonicum)** | 經皮穿入（尾蚴 Cercaria） | 釘螺（Oncomelania） | 門脈高壓、肝脾腫大、腸道病變。首選 Praziquantel。 |
| **埃及血吸蟲 (Schistosoma haematobium)** | 經皮穿入（尾蚴 Cercaria） | 水螺（Bulinus） | 無痛血尿、**膀胱鱗狀上皮細胞癌**。首選 Praziquantel。 |
| **豬肉絛蟲 (Taenia solium)** | 食入生豬肉囊尾蚴（腸道絛蟲症）；**食入蟲卵引發囊蟲症 (Cysticercosis)** | 豬（囊蟲症時人為中間宿主） | 腦囊蟲症（癲癇發作、腦室水腦症）。 |
| **牛肉絛蟲 (Taenia saginata)** | 食入生牛肉囊尾蚴 | 牛 | 僅造成腸道消化不良，**不會在人體引起囊蟲症**。 |
| **廣節裂頭絛蟲 (Diphyllobothrium latum)** | 食入生淡水魚裂頭蚴 | 劍水蚤 $\rightarrow$ 淡水魚 | 吸收宿主體內維生素 $B_{12}$，造成**巨球性巨幼紅血球貧血**。 |
