# 腎臟生理學高頻考點

## 腎絲球過濾與清除率計算

### 關鍵公式

1. **腎絲球過濾率 (GFR)**：使用菊糖（Inulin）或肌酸酐（Creatinine）清除率評估：
   $$GFR = C_{\text{inulin}} = \frac{U_{\text{inulin}} \times V}{P_{\text{inulin}}}$$
2. **有效腎血漿流量 (ERPF)**：使用對位胺基馬尿酸（PAH）清除率評估：
   $$ERPF = C_{\text{PAH}} = \frac{U_{\text{PAH}} \times V}{P_{\text{PAH}}}$$
3. **過濾分率 (Filtration Fraction, FF)**：
   $$FF = \frac{GFR}{RPF} \approx 20\%$$

## 腎小管各段再吸收與利尿劑作用點

| 腎小管部位 | 主要轉運蛋白 / 機轉 | 作用於此之利尿劑 | 國考重點 |
| :--- | :--- | :--- | :--- |
| **近曲小管 (PCT)** | $\text{Na}^+/\text{H}^+$ 交換體、碳酸酐酶（CA） | 乙醯偶氮胺 (Acetazolamide) | 67% 的鈉水再吸收，100% 葡萄糖與胺基酸再吸收 |
| **亨利氏環粗上升支 (TAL)** | $\text{Na}^+-\text{K}^+-2\text{Cl}^-$ 共同轉運蛋白 (NKCC2) | 袢利尿劑 (Furosemide, Bumetanide) | 破壞髓質高滲梯度，造成高尿鈣與低血鉀 |
| **遠曲小管早期 (DCT)** | $\text{Na}^+-\text{Cl}^-$ 共同轉運蛋白 (NCC) | 噻嗪類利尿劑 (Thiazides) | 促進鈣質再吸收，造成低尿鈣、高血鈣與低血鉀 |
| **皮質集尿管 (CCT)** | 上皮鈉通道 (ENaC)、醛固酮調節 | 保鉀利尿劑 (Spironolactone, Amiloride) | 受醛固酮與 ADH 調節，排鉀留鈉、調節酸鹼 |
