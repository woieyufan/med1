# 呼吸生理學高頻考點

## 氧合血紅素解離曲線（Oxyhemoglobin Dissociation Curve）

!!! tip "曲線右偏 (Shift to Right)"
    代表血紅素對氧的親和力**下降**，促進氧氣釋放至周邊組織。

口訣：**CADET, face Right!**
- **C**：$\text{CO}_2$ 分壓上升（Bohr effect）
- **A**：Acidity 上升（pH 下降 / 變酸）
- **D**：2,3-DPG（2,3-BPG）濃度上升（高山缺氧、慢性貧血）
- **E**：Exercise 運動
- **T**：Temperature 體溫升高

## 通氣/灌流比（V/Q Ratio）極端情況

| 狀態 | $V/Q$ 比值 | 肺泡分壓表現 | 臨床經典疾病 |
| :--- | :--- | :--- | :--- |
| **正常基底至肺尖** | 肺尖約 3.0，肺底約 0.6 | 肺尖相對高氧、低二氧化碳 | 結核菌（TB）好發於肺尖（高氧環境） |
| **分流 (Shunt)** | $V/Q \rightarrow 0$ | $P_{A}O_2 \rightarrow 40\text{ mmHg}, P_{A}CO_2 \rightarrow 46\text{ mmHg}$ | 肺不張（Atelectasis）、異物吸入、ARDS。**給予 100% 氧氣無法矯正低血氧**。 |
| **死腔 (Dead space)** | $V/Q \rightarrow \infty$ | $P_{A}O_2 \rightarrow 150\text{ mmHg}, P_{A}CO_2 \rightarrow 0\text{ mmHg}$ | 肺栓塞（Pulmonary Embolism，血流阻斷但通氣存在） |
