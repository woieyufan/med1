# 心血管生理學高頻考點

## 心室壓力-容積循環（PV Loop）

PV Loop 是心血管生理中最常出現的圖形題考點。

```
心室壓力 (mmHg)
  ▲
  │        C (主動脈瓣開啟) ───────── D (主動脈瓣關閉, ESV)
  │        │                          │
  │        │ 等容收縮                 │ 等容舒張
  │        │                          │
  │        B (二尖瓣關閉, EDV) ────── A (二尖瓣開啟)
  └────────────────────────────────────────► 心室容積 (mL)
```

| 關鍵指標 | 計算公式與生理意涵 | 影響因素 |
| :--- | :--- | :--- |
| **心搏量 (Stroke Volume, SV)** | $SV = EDV - ESV$ | 前負荷增加 $\rightarrow$ SV 增加；後負荷增加 $\rightarrow$ SV 下降；心肌收縮力增加 $\rightarrow$ SV 增加 |
| **射出分率 (Ejection Fraction, EF)** | $EF = \frac{SV}{EDV} \times 100\%$ | 正常值約 $55 \sim 70\%$；收縮性心衰竭時 $EF < 40\%$ |
| **心輸出量 (Cardiac Output, CO)** | $CO = HR \times SV = \frac{\dot{V}_{O_2}}{C_a - C_v}$ (Fick Principle) | 運動時可增至 4~5 倍 |
| **平均動脈壓 (MAP)** | $MAP = DBP + \frac{1}{3}(SBP - DBP) = CO \times TPR$ | 舒張壓對平均壓影響佔 $2/3$ 比重 |

## 壓力感受器反射（Baroreceptor Reflex）

- **頸動脈竇 (Carotid sinus)**：經由**舌下/舌咽神經 (CN IX)** 傳入延腦孤立束核（NTS）。感受血壓上升與下降。
- **主動脈弓 (Aortic arch)**：經由**迷走神經 (CN X)** 傳入。主要僅感應血壓上升。
- **動脈瘤或頸動脈按摩效應**：刺激頸動脈竇 $\rightarrow$ 興奮副交感、抑制交感 $\rightarrow$ 心跳變慢、血管舒張、血壓下降。
