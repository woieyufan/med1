# 神經肌肉與內分泌生理學高頻考點

## 骨骼肌收縮與平滑肌對比

| 比較項目 | 骨骼肌 (Skeletal Muscle) | 平滑肌 (Smooth Muscle) |
| :--- | :--- | :--- |
| **鈣離子結合蛋白** | **肌鈣蛋白 C (Troponin C)** | **鈣調蛋白 (Calmodulin, CaM)** |
| **活化酵素機轉** | 暴露肌動蛋白結合位，粗細肌絲滑動 | 鈣-鈣調蛋白複合物活化**肌凝蛋白輕鏈激酶 (MLCK)** |
| **橫小管 (T-tubule)** | 有（形成三聯體 Triad: T-tubule + 兩側終池） | 無（以小凹 Caveolae 取代） |
| **細胞外鈣離子依賴度** | 低（主要依賴肌漿網 RyR 釋放鈣） | 極高（依賴細胞外鈣流入與 IP3 釋放鈣） |

## 內分泌二次信使系統分類

!!! tip "國考記憶歸納"
    - **cAMP 途徑 (FLAT ChAMP)**：FSH, LH, ACTH, TSH, CRH, hCG, ADH ($V_2$), MSH, PTH, Glucagon, Calcitonin.
    - **$\text{IP}_3/\text{DAG}/\text{Ca}^{2+}$ 途徑 (GOAT HAG)**：GnRH, Oxytocin, ADH ($V_1$), TRH, Histamine ($H_1$), Angiotensin II, Gastrin.
    - **酪胺酸激酶 (Receptor Tyrosine Kinase, RTK)**：Insulin, IGF-1, PDGF, EGF, FGF.
    - **細胞核受體 (Nuclear / Steroid receptors)**：甲狀腺素（T3/T4）、維生素 D、皮質醇、醛固酮、雌激素、雄性素、黃體素。
