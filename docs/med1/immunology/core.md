# 免疫學核心機制與過敏反應

## 第 I~IV 型過敏反應（Hypersensitivity Reactions）

口訣：**ACID** (I - **A**llergy, II - **C**ytotoxic, III - **I**mmune complex, IV - **D**elayed)

| 類型 | 致病機轉與主要介質 | 發作時間 | 典型臨床疾病代表 |
| :--- | :--- | :--- | :--- |
| **第 I 型 (即發型 / Anaphylactic)** | 抗原與肥大細胞表面 **IgE** 結合，促使組織胺、白三烯（$LTC_4, LTD_4$）去顆粒釋放 | 數分鐘至數小時 | 過敏性休克（Anaphylaxis）、氣喘、過敏性鼻炎、蕁麻疹 |
| **第 II 型 (細胞毒型 / Antibody-mediated)** | **IgM 或 IgG** 結合於**固定細胞或組織抗原**，透過補體 MAC、ADCC 或調理吞噬破壞 | 數小時至數天 | 自體免疫溶血性貧血（AIHA）、Goodpasture 症候群、重症肌無力、Graves 病 |
| **第 III 型 (免疫複合物型)** | **抗原-抗體（IgG）可溶性複合物**沉積於微血管壁或基底膜，活化補體引發嗜中性球浸潤 | 1~2 週 | 全身性紅斑狼瘡（SLE）、急性鏈球菌感染後腎炎（PSGN）、血清病（Serum sickness） |
| **第 IV 型 (遲發型 / Cell-mediated)** | 致敏之 **CD4+ Th1/Th17 或 CD8+ T 細胞**釋放細胞激素（IFN-$\gamma$）活化巨噬細胞，**無抗體參與** | 48~72 小時 | 結核菌素試驗（PPD test）、接觸性皮膚炎（毒藤、鎳過敏）、多發性硬化症（MS） |
