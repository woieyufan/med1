# 生物化學代謝路徑高頻考點

## 糖解作用、糖質新生與調節酵素

| 代謝步驟 | 糖解作用關鍵酵素 (Glycolysis) | 糖質新生對應酵素 (Gluconeogenesis) | 調節因子與生化意涵 |
| :--- | :--- | :--- | :--- |
| **第一不可逆反應** | 己糖激酶 (Hexokinase) / 葡萄糖激酶 (Glucokinase) | 葡萄糖-6-磷酸酶 (Glucose-6-phosphatase) | 葡萄糖激酶位於肝臟與胰島 $\beta$ 細胞（高 $K_m$、高 $V_{\max}$，受胰島素誘導）；G6Pase 缺乏導致第 I 型肝醣儲積症 (von Gierke)。 |
| **第二不可逆反應（限速步驟）** | **磷酸果糖激酶-1 (PFK-1)** | 果糖-1,6-雙磷酸酶 (FBPase-1) | **果糖-2,6-雙磷酸 ($F-2,6-BP$) 是 PFK-1 最強變構活化劑**；胰島素增加 $F-2,6-BP$，促進糖解；升糖素降低之。 |
| **第三不可逆反應** | 丙酮酸激酶 (Pyruvate kinase) | 丙酮酸羧化酶 + PEP 羧激酶 (PC + PEPCK) | 丙酮酸羧化酶需要生物素（Biotin, B7）與 ATP，在粒線體內將丙酮酸轉化為草醯乙酸 (OAA)。 |

## 肝醣儲積症（Glycogen Storage Diseases）速記

口訣：**V**ery **P**oor **C**arb **M**etabolism (I - **V**on Gierke, II - **P**ompe, III - **C**ori, V - **M**cArdle)

| 類型 | 缺乏酵素 | 累積物質 | 經典臨床特徵 |
| :--- | :--- | :--- | :--- |
| **第 I 型 (von Gierke)** | 葡萄糖-6-磷酸酶 (G6Pase) | 肝腎內肝醣結構正常但無法分解 | 嚴重空腹低血糖、高乳酸血症、高尿酸血症（痛風）、高血脂、娃娃臉。 |
| **第 II 型 (Pompe)** | 溶體 $\alpha$-1,4-葡萄糖苷酶 (酸性麥芽糖酶) | 溶體內肝醣堆積 | **心肌肥大肥厚**（Pompe trashes the **Pump**）、嬰兒期心衰竭致死。 |
| **第 III 型 (Cori)** | 去分支酵素 (Debranching enzyme, $\alpha$-1,6-glucosidase) | 異常短外鏈分枝肝醣 (Limit dextrin) | 症狀類似第 I 型但較輕微，**血乳酸正常**，肌力正常。 |
| **第 V 型 (McArdle)** | 骨骼肌肝醣磷酸化酶 (Myophosphorylase) | 骨骼肌內肝醣無法分解利用 | 劇烈運動後肌肉抽筋痙攣、肌球蛋白尿（茶色尿，**McArdle = Muscle**）。 |
