# 分子生物學與遺傳學高頻考點

## DNA 複製酵素與原核/真核對比

| 功能角色 | 原核生物 (E. coli) | 真核生物 (Eukaryotes) | 臨床重要抑制劑 / 藥物 |
| :--- | :--- | :--- | :--- |
| **解旋酶 (Helicase)** | DnaB | MCM 複合體 | 解開雙股 DNA，需要消耗 ATP |
| **引子合成酶 (Primase)** | DnaG | Pol $\alpha$ (附帶 primase) | 合成一段短 RNA 引子 |
| **主要延長聚合酶** | **DNA Pol III** (具 $3'\rightarrow 5'$ 校對核酸外切酶活性) | **Pol $\delta$** (落後股) / **Pol $\varepsilon$** (領先股) | 具極高持續合成能力與校對能力 |
| **移除 RNA 引子** | **DNA Pol I** (具 $5'\rightarrow 3'$ 外切活性並填補空隙) | RNase H + FEN1 + Pol $\delta$ | 原核 Pol I 是唯一具 $5'\rightarrow 3'$ 校對/切除活性者 |
| **拓撲異構酶 (Topoisomerase)** | DNA 旋轉酶 (DNA Gyrase / Topo II) | Topoisomerase I / II | **Fluoroquinolones** 抑制細菌 Gyrase；**Etoposide** 抑制真核 Topo II；**Irinotecan** 抑制 Topo I |

## 常用實驗診斷技術速查

- **Southern blot**：偵測 **DNA** 片段（使用標記 DNA/RNA 探針）。
- **Northern blot**：偵測 **mRNA** 表現量（評估基因轉錄層次）。
- **Western blot**：偵測 **蛋白質 (Protein)**（使用特異性抗體，如確診 HIV）。
- **PCR (聚合酶連鎖反應)**：體外大量擴增特定 DNA 序列（需要耐熱 Taq DNA 聚合酶、dNTP、一對寡核苷酸引子）。
- **ELISA**：酵素免疫分析法，用於抗原或抗體定量篩檢（如 HIV 初篩、B 肝抗原檢測）。
