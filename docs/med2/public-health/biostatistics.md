# 生物統計學高頻考點

## 統計假設檢定方法選擇決策樹

| 自變項型態 (Independent) | 依變項型態 (Dependent) | 檢定方法名稱 | 國考經典情境範例 |
| :--- | :--- | :--- | :--- |
| **類別型 (2組獨立)** | **連續型 (常態分佈)** | **獨立樣本 t 檢定 (Two-sample t-test)** | 比較新降壓藥組與對照組病患的平均收縮壓 |
| **類別型 (2組相依/配對)** | **連續型 (常態分佈)** | **成對樣本 t 檢定 (Paired t-test)** | 比較同一群受試者在服藥前後的血壓變化 |
| **類別型 ($\ge 3$ 組獨立)** | **連續型 (常態分佈)** | **單因子變異數分析 (One-way ANOVA)** | 比較低劑量、中劑量、高劑量三組病患的平均血糖值 |
| **類別型 (任一維度)** | **類別型 (次數或百分比)** | **卡方檢定 ($\chi^2$ test)** | 比較抽菸與不抽菸兩組罹患肺癌的罹病率（2x2 列聯表） |
| **連續型** | **連續型** | **皮爾森相關分析 (Pearson r) / 線性迴歸** | 探討年齡與體脂率的線性關聯性 |

## 第一型與第二型錯誤（Type I & II Errors）

| 實際狀況 | 拒絕虛無假設 $H_0$（檢定有顯著差異） | 接受/不拒絕虛無假設 $H_0$（檢定無顯著差異） |
| :--- | :--- | :--- |
| **真實 $H_0$ 為真（兩組實際無差異）** | **型 I 錯誤 ($\alpha$, 偽陽性)**；設定顯著水準通常為 0.05 | 正確決策 ($1-\alpha$, 信心水準) |
| **真實 $H_1$ 為真（兩組實際有差異）** | 正確決策 (**$1-\beta$, 統計檢定力 Power**) | **型 II 錯誤 ($\beta$, 偽陰性)** |

- **提升檢定力（Power, $1-\beta$）的方法**：
  1. 增加樣本數 $N$。
  2. 放大顯著水準 $\alpha$（如從 0.01 放寬至 0.05）。
  3. 效應值（Effect size）增大。
  4. 減少測量誤差與變異量。
