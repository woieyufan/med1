# 衛生法規與預防醫學高頻考點

## 三段五級預防概念（Leavell & Clark）

| 預防階段 | 級別與工作內容 | 具體醫療與公衛實踐代表 |
| :--- | :--- | :--- |
| **初段預防 (Primary)** | **第一級：健康促進**<br>改善個人健康狀況與環境素養 | 均衡飲食、衛生教育、規律運動、戒菸宣導 |
| | **第二級：特殊保護**<br>阻斷特定致病因子接觸 | **常規疫苗接種**、戴口罩、高危險群預防性投藥（PrEP）、氟化物防齲 |
| **次段預防 (Secondary)** | **第三級：早期診斷、早期治療**<br>在疾病臨床前期偵測病變 | **成人健檢、四癌篩檢（子宮頸抹片、乳房攝影、糞便潛血、口腔黏膜檢查）**、新生兒先天代謝篩檢 |
| **末段預防 (Tertiary)** | **第四級：限制殘障**<br>阻止疾病進展與急性併發症 | 糖尿病患者定期眼底與足部檢查避免截肢失明、中風急性期藥物治療 |
| | **第五級：復健**<br>恢復身體與社會功能 | 中風後物理與職能復健、安寧緩和醫療、心臟復健計畫 |

## 法定傳染病分類與報告時限（傳染病防治法）

| 類別 | 通報時限規範 | 代表法定傳染病 |
| :--- | :--- | :--- |
| **第一類** | **24 小時內通報**，必要時得強制隔離 | 天花、鼠疫、嚴重急性呼吸道症候群 (SARS)、狂犬病 |
| **第二類** | **24 小時內通報**，必要時得隔離 | 登革熱、麻疹、霍亂、白喉、德國麻疹、痢疾阿米巴、瘧疾、漢他病毒 |
| **第三類** | **1 週內通報**（部分 24 小時內） | 結核病（1 週內）、人類免疫缺乏病毒 (HIV, 24 小時)、急性病毒性 B/C 肝、退伍軍人病 |
| **第四類** | 依主管機關公告時限（多為 1 週內） | 水痘、流感併發重症、破傷風、肉毒桿菌中毒 |
| **第五類** | **24 小時內通報** | 新興影響重大傳染病（如 COVID-19 早期、中東呼吸症候群冠狀病毒 MERS-CoV、伊波拉病毒） |
