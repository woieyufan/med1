# 流行病學高頻考點

## 流行病學研究設計對比

| 研究設計型態 | 收案切入點 | 核心風險指標 | 主要優缺點與國考陷阱 |
| :--- | :--- | :--- | :--- |
| **橫斷研究 (Cross-sectional)** | 同一時間點同時測量暴露與疾病 | **盛行率 (Prevalence)** | 便宜迅速；無法判定因果暴露的時間先後順序（時序性不明）。 |
| **病例對照研究 (Case-control)** | 先以**有無生病**分組，回溯過去暴露史 | **勝算比 (Odds Ratio, OR)** | 適合研究**罕見疾病**或潛伏期長之疾病；容易產生**回憶偏差 (Recall bias)**。 |
| **世代研究 (Cohort study)** | 先以**有無暴露**分組，前瞻或回溯追蹤後續發病 | **相對危險度 (Relative Risk, RR)**、歸因危險度 (AR) | 可直接計算發生率；適合研究**罕見暴露**；耗時昂貴，容易有**失訪偏差 (Loss to follow-up)**。 |
| **隨機對照試驗 (RCT)** | 隨機分派暴露/處置介入 | 相對危險度、需治療人數 (NNT) | 因果推論證據力最高；倫理考量限制多。 |

## 篩檢工具效能評估計算

```
                    真病存在 (Disease +)   真病不存在 (Disease -)
篩檢陽性 (Test +)           a (TP)                b (FP)           => a + b
篩檢陰性 (Test -)           c (FN)                d (TN)           => c + d
                         ───────               ───────
                          a + c                 b + d
```

1. **敏感度 (Sensitivity)**：真病者中篩檢為陽性之比率：
   $$\text{Sensitivity} = \frac{a}{a+c} = \frac{TP}{TP+FN}$$
2. **特異度 (Specificity)**：無病者中篩檢為陰性之比率：
   $$\text{Specificity} = \frac{d}{b+d} = \frac{TN}{FP+TN}$$
3. **陽性預測值 (PPV)**：篩檢陽性者中真正有病之機率：
   $$\text{PPV} = \frac{a}{a+b}$$
4. **盛行率 (Prevalence) 對預測值的影響（國考必考題）**：
   - 盛行率增加 $\rightarrow$ **PPV 上升**、**NPV 下降**。
   - 敏感度與特異度為篩檢工具本質特性，**不受疾病盛行率高低影響**。
