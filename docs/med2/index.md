# 醫學（二）核心考點總彙編（共 41 章）

醫學（二）總題數 100 題（第 1 題至第 100 題），為連結基礎醫學與臨床診療的關鍵前哨站。各科緊密圍繞「分子機轉 $\to$ 病理形態 $\to$ 藥物治療 $\to$ 群體流行病預防」。

---

## 醫學（二）配分題數與科目分布

| 科目名稱 | 考選部題號範圍 | 題數分配 | 核心衝刺策略 |
| :--- | :--- | :--- | :--- |
| **生物化學與分子生物學** | Q1 ~ Q27 | 約 27 題 | 聚焦三大代謝限速酵素、一碳循環、分子生物學中心法則與代謝缺陷遺傳病。 |
| **基礎與臨床藥理學** | Q28 ~ Q54 | 約 27 題 | 自律神經受體、心血管用藥、中樞神經藥、抗生素靶點與抗癌標靶化療。 |
| **人體病理學** | Q55 ~ Q80 | 約 26 題 | 細胞損傷壞死、發炎修復與肉芽腫、腫瘤分子分期，緊密搭配各器官系統病變。 |
| **公共衛生學** | Q81 ~ Q100 | 約 20 題 | 生統假說檢定公式、流病研究設計與因果推論、篩檢敏感特異度、健保法規。 |
