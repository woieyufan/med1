# 中樞神經藥理學高頻考點

## 鎮靜安眠藥：Benzodiazepines vs Barbiturates

| 比較項目 | 苯二氮平類 (Benzodiazepines, BZD) | 巴比妥鹽類 (Barbiturates) |
| :--- | :--- | :--- |
| **代表藥物** | Diazepam, Lorazepam, Midazolam | Phenobarbital, Thiopental |
| **分子作用機轉** | 結合於 $\text{GABA}_A$ 受體變構調節位，增加氯離子通道**開啟頻率 (Frequency)** | 結合於不同結合位，增加氯離子通道**開啟持續時間 (Duration)**；高濃度下可直接開啟通道 |
| **安全性與治療指數** | 高（具平原效應，不易單獨致死） | 低（呼吸抑制風險極高，昏迷致死） |
| **特異性解毒劑** | **Flumazenil**（競爭性拮抗 BZD 結合位） | **無特異解毒劑**（給予碳酸氫鈉鹼化尿液加速排泄） |

## 抗精神病藥物：第一代 vs 第二代

| 分類 | 第一代抗精神病藥 (Typical / FGA) | 第二代抗精神病藥 (Atypical / SGA) |
| :--- | :--- | :--- |
| **代表藥物** | Haloperidol, Chlorpromazine, Fluphenazine | Clozapine, Olanzapine, Risperidone, Quetiapine |
| **主要受體機轉** | 強效阻斷中樞多巴胺 **$D_2$ 受體** | 雙重阻斷多巴胺 **$D_2$ 與血清素 $5-\text{HT}_{2A}$ 受體** |
| **療效範圍** | 主要改善幻覺、妄想等**正性症狀** | 同時改善**正性症狀與負性症狀**（情感淡漠、社交退縮） |
| **核心副作用** | **錐體外路徑症候群 (EPS)**：急性肌張力障礙、靜坐不能、巴金森氏症候群、遲發性運動障礙；高泌乳素血症。 | **代謝症候群**：體重增加、高血糖、高血脂（以 Olanzapine, Clozapine 最顯著）。 |
| **致命併發症 / 警語** | 抗精神病藥物惡性症候群 (NMS，高熱、鉛管僵直，解毒劑 Dantrolene / Bromocriptine)。 | **Clozapine 具顆粒球缺乏症 (Agranulocytosis)** 風險，需定期監測 ANC。 |
