# 自律神經藥理學高頻考點

## 腎上腺素受體分類與作用機轉

| 受體亞型 | G 蛋白偶聯途徑 | 二次信使 / 離子通道 | 主要組織分佈與生理反應 | 經典促效劑 (Agonist) / 拮抗劑 (Antagonist) |
| :--- | :--- | :--- | :--- | :--- |
| **$\alpha_1$** | $G_q$ | $\uparrow \text{IP}_3 / \text{DAG} \rightarrow \uparrow \text{Ca}^{2+}$ | 血管平滑肌收縮（血壓升高）、瞳孔散大肌收縮（散瞳）、膀胱括約肌收縮 | **促**：Phenylephrine<br>**抗**：Prazosin, Doxazosin（降血壓、治療 BPH） |
| **$\alpha_2$** | $G_i$ | $\downarrow \text{cAMP}$ | 突觸前自體受體（抑制 NE 釋放）、胰島 $\beta$ 細胞（抑制胰島素釋放） | **促**：Clonidine, $\alpha$-Methyldopa（中樞降壓）<br>**抗**：Yohimbine |
| **$\beta_1$** | $G_s$ | $\uparrow \text{cAMP}$ | 心臟（心跳加快、收縮力增強）、近腎絲球細胞（促進腎素 Renin 分泌） | **促**：Dobutamine<br>**抗**：Atenolol, Metoprolol, Bisoprolol（心臟選擇性） |
| **$\beta_2$** | $G_s$ | $\uparrow \text{cAMP}$ | 支氣管平滑肌舒張、血管平滑肌舒張、促進肝醣分解、促進鉀離子進入細胞 | **促**：Albuterol, Salmeterol（氣喘解痙）<br>**抗**：Propranolol（非選擇性，氣喘禁用） |
| **$\beta_3$** | $G_s$ | $\uparrow \text{cAMP}$ | 脂肪細胞（促進脂肪分解）、膀胱逼尿肌（舒張逼尿肌） | **促**：Mirabegron（治療膀胱過動症 OAB） |

## 膽鹼性毒性 vs 抗膽鹼中毒鑑別

| 症狀表現 | 膽鹼致效劑中毒（如有機磷農藥）口訣：**DUMBBELLS** | 抗膽鹼藥物中毒（如 Atropine）口訣：**Mad as a hatter, Blind as a bat** |
| :--- | :--- | :--- |
| **神經系統與精神狀態** | 意識混亂、抽搐、中樞呼吸抑制 | 狂躁、譫妄、幻覺、躁動不安 |
| **瞳孔狀態** | **針尖樣縮瞳 (Miosis)** | **顯著散瞳 (Mydriasis)**、畏光調節麻痺 |
| **分泌物與排泄** | 大量流涎、流淚、多尿、腹瀉、多汗、支氣管分泌物過多 | 口乾舌燥、無汗、尿液滯留、便秘 |
| **心血管表現** | 心跳過緩（Bradycardia）或低血壓 | 心跳過速（Tachycardia）、潮紅灼熱（Flushing） |
| **特異性解毒劑** | **Atropine**（競爭毒蕈鹼受體）+ **Pralidoxime (2-PAM)**（重活化乙醯膽鹼酯酶） | **Physostigmine**（可通過血腦障壁之膽鹼酯酶抑制劑） |
