# 病理學總論高頻考點

## 細胞壞死（Necrosis）型態分類與臨床疾病對照

| 壞死類型 | 組織病理學特徵 | 主要好發組織 | 經典臨床疾病代表 |
| :--- | :--- | :--- | :--- |
| **凝固性壞死 (Coagulative)** | 組織基本架構與輪廓保存數天，細胞核溶解消失（鬼影細胞 Ghost cells） | 除腦以外的所有實質器官缺血梗塞 | **心肌梗塞 (MI)**、腎臟梗塞、脾臟梗塞 |
| **液化性壞死 (Liquefactive)** | 組織被水解酵素完全溶解為黏稠液體，形成膿瘍或囊腔 | **中樞神經系統缺血梗塞**、化膿性細菌/真菌感染 | **腦中風梗塞**、細菌性肺膿瘍、化膿性肝膿瘍 |
| **乾酪性壞死 (Caseous)** | 肉眼見白色乳酪狀無結構豆腐渣碎屑；鏡下為無結構嗜酸性粉末，周圍肉芽腫浸潤 | 結核菌、真菌感染 | **結核病 (Tuberculosis)**、全身性真菌病（組織胞漿菌） |
| **脂肪壞死 (Fat necrosis)** | 脂肪酸釋出與鈣離子結合形成白色白堊狀不溶性沉積（皂化反應 Saponification） | 胰臟周圍脂肪、乳房外傷 | **急性胰臟炎**（脂肪酶外漏）、乳房鈍挫傷 |
| **纖維素樣壞死 (Fibrinoid)** | 血管壁通透性增加，抗原-抗體複合物與纖維蛋白外滲，染色呈鮮亮濃粉紅色 | 動脈壁、免疫複合物沉積處 | **結節性多動脈炎 (PAN)**、惡性高血壓、子癇前症胎盤血管 |

## 腫瘤標記（Tumor Markers）速查表

- **AFP ($\alpha$-Fetoprotein)**：肝細胞癌（HCC）、非精原細胞性睪丸胚胎癌、卵黃囊瘤（Yolk sac tumor）。
- **CEA (Carcinoembryonic antigen)**：大腸直腸癌（主要用於術後復發監測）、胰臟癌、胃癌。
- **CA-125**：卵巢上皮細胞癌（漿液性囊腺癌）。
- **CA 19-9**：胰臟癌、膽管癌。
- **PSA (Prostate-specific antigen)**：攝護腺癌（良性攝護腺肥大與攝護腺炎亦可輕度升高）。
- **hCG (人類絨毛膜促性腺激素)**：絨毛膜癌（Choriocarcinoma）、葡萄胎、睪丸胚胎生殖細胞瘤。
- **S-100**：黑色素瘤（Melanoma）、神經鞘瘤（Schwannoma）、蘭格罕氏細胞組織球增生症（LCH）。
